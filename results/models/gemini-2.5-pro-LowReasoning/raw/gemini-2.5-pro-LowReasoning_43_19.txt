// This is a simple pixel shader that outputs a solid color.

// The pixel shader takes no special inputs for this simple example.
// It will output a single color value.

// The output of the pixel shader is a 4-component vector (RGBA).
// The SV_Target semantic indicates that this is the color to be written to the render target.
float4 main() : SV_Target
{
    // Return a solid red color (RGBA)
    return float4(1.0f, 0.0f, 0.0f, 1.0f);
}
