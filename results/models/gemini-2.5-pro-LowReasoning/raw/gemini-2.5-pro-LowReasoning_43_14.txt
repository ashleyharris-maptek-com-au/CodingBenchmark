// A simple pixel shader that outputs a solid color.

// The output of the pixel shader is a 4-component float vector (RGBA).
// The `SV_TARGET` semantic indicates that this is the primary render target.
// For Vulkan, we specify the binding location using `register(bX, spaceY)`.
// `register(b0)` maps to `layout(location = 0) out` in GLSL/SPIR-V.
float4 main() : SV_TARGET
{
    // Return a solid magenta color (Red=1, Green=0, Blue=1, Alpha=1)
    return float4(1.0, 0.0, 1.0, 1.0);
}
