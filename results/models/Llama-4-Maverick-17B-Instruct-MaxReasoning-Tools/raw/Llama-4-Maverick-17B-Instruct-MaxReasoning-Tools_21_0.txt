# Problem Understanding

The problem requires writing a C++ solver to play an N-Dimensional Snake Game. The game is a generalization of the classic Nokia snake game to arbitrary dimensions. The snake occupies a series of connected integer grid points in N-D space, moves one step per turn along one axis (+1 or -1), grows when eating food, and dies if it hits an obstacle or itself.

Key constraints and edge cases:

- The game can have any number of dimensions (D) from 2 to 20.
- The size of the space in each dimension is given by the input bounds.
- The snake's initial length and starting position are provided.
- The number and positions of food items and obstacles are given.
- The game ends when the snake eats all food, hits an obstacle or itself, or reaches the maximum number of turns.
- The input format is specified, with D, max_turns, bounds, snake_length, start_pos, food items, and obstacles provided through stdin.
- The output format requires printing the axis and direction of the snake's movement each turn.

Input: D, max_turns, bounds, snake_length, start_pos, food items, and obstacles.
Output: Axis and direction of the snake's movement each turn.

Subtle requirements:

- The algorithm must work efficiently across all dimensionalities.
- The solution should be compatible with the given C++ compiler (MSVC cl 19.50.35730) and environment (Windows 11, AMD64 architecture).

# Key Insights

- The problem requires a pathfinding algorithm that can work in N-dimensional space.
- A simple heuristic for the snake to follow is to move towards the nearest food item.
- Calculating the distance between the snake's head and food items in N-dimensional space is necessary.
- The distance can be calculated using the Manhattan distance (L1 distance) since the snake moves along one axis at a time.
- The snake's movement should be validated to avoid hitting obstacles or itself.
- The algorithm should prioritize movements that keep the snake alive and progress towards eating food.
- BFS or a similar algorithm can be used to find a path to the food in N-dimensional space while avoiding obstacles and the snake's body.
- The snake's body occupancy in N-dimensional space needs to be managed efficiently.

Critical examples or test cases:

- Simple 2D games with few obstacles.
- Higher-dimensional games (3D-20D) with moderate to many obstacles.

# Solution Strategy

1. Parse the input to extract the number of dimensions (D), maximum turns, bounds, snake's initial length and position, food items, and obstacles.
2. Implement a data structure to represent points in N-dimensional space using `std::vector<int>`.
3. Use a BFS algorithm to find the nearest food item and a valid path to it while avoiding obstacles and the snake's body.
4. Calculate the Manhattan distance between the snake's head and food items to determine the nearest food.
5. Validate the snake's movements to ensure they are within the bounds and do not hit obstacles or the snake's body.
6. Update the snake's position and body occupancy after each move.
7. Check for game-ending conditions (eating all food, hitting an obstacle or itself, or reaching the maximum turns) after each move.
8. Output the axis and direction of the snake's movement each turn in the required format.

def get_next_move(head, food, snake_body, obstacles, bounds):
    nearest_food = min(food, key=lambda x: manhattan_distance(head, x))
    path = bfs(head, nearest_food, snake_body, obstacles, bounds)
    if path and len(path) > 1:
        next_pos = path[1]
        for d in range(len(head)):
            if next_pos[d] != head[d]:
                return d, next_pos[d] - head[d]
    return None

def bfs(start, target, snake_body, obstacles, bounds):
    queue = deque([[start]])
    visited = set([tuple(start)])
    snake_body_set = set(snake_body)
    
    while queue:
        path = queue.popleft()
        current = path[-1]
        if current == target:
            return path
        for d in range(len(current)):
            for dir in [-1, 1]:
                new_pos = list(current)
                new_pos[d] += dir
                if tuple(new_pos) not in visited and is_valid(new_pos, snake_body_set, obstacles, bounds):
                    queue.append(path + [new_pos])
                    visited.add(tuple(new_pos))
    return None

def is_valid(pos, snake_body, obstacles, bounds):
    if tuple(pos) in snake_body or tuple(pos) in obstacles:
        return False
    for i in range(len(pos)):
        if pos[i] < 0 or pos[i] >= bounds[i]:
            return False
    return True

def is_valid_move(new_pos, snake_body, obstacles, bounds):
    snake_body_set = set(snake_body)
    return is_valid(new_pos, snake_body_set, obstacles, bounds)

def manhattan_distance(pos1, pos2):
    return sum(abs(a - b) for a, b in zip(pos1, pos2))

if __name__ == "__main__":
    main()

#include <iostream>
#include <vector>
#include <queue>
#include <set>
#include <deque>
#include <algorithm>

using namespace std;

struct Position : public vector<int> {
    Position(const vector<int>& pos) : vector<int>(pos) {}
    bool operator==(const Position& other) const {
        return this->size() == other.size() && equal(this->begin(), this->end(), other.begin());
    }
};

struct PositionHash {
    size_t operator()(const Position& pos) const {
        size_t hash = 0;
        for (int x : pos) {
            hash = hash * 31 + x;
        }
        return hash;
    }
};

int manhattan_distance(const Position& pos1, const Position& pos2) {
    int distance = 0;
    for (size_t i = 0; i < pos1.size(); ++i) {
        distance += abs(pos1[i] - pos2[i]);
    }
    return distance;
}

bool is_valid(const Position& pos, const set<Position, PositionHash>& snake_body, const set<Position, PositionHash>& obstacles, const vector<int>& bounds) {
    if (snake_body.find(pos) != snake_body.end() || obstacles.find(pos) != obstacles.end()) {
        return false;
    }
    for (size_t i = 0; i < pos.size(); ++i) {
        if (pos[i] < 0 || pos[i] >= bounds[i]) {
            return false;
        }
    }
    return true;
}

vector<Position> bfs(const Position& start, const Position& target, const deque<Position>& snake_body, const set<Position, PositionHash>& obstacles, const vector<int>& bounds) {
    queue<vector<Position>> q;
    q.push({start});
    set<Position, PositionHash> visited;
    visited.insert(start);
    set<Position, PositionHash> snake_body_set(snake_body.begin(), snake_body.end());
    
    while (!q.empty()) {
        auto path = q.front();
        q.pop();
        auto current = path.back();
        if (current == target) {
            return path;
        }
        for (size_t d = 0; d < current.size(); ++d) {
            for (int dir : {-1, 1}) {
                Position new_pos = current;
                new_pos[d] += dir;
                if (visited.find(new_pos) == visited.end() && is_valid(new_pos, snake_body_set, obstacles, bounds)) {
                    auto new_path = path;
                    new_path.push_back(new_pos);
                    q.push(new_path);
                    visited.insert(new_pos);
                }
            }
        }
    }
    return {};
}

pair<int, int> get_next_move(const Position& head, const vector<Position>& food, const deque<Position>& snake_body, const set<Position, PositionHash>& obstacles, const vector<int>& bounds) {
    if (food.empty()) return {-1, -1};
    auto nearest_food = *min_element(food.begin(), food.end(), [&head](const Position& a, const Position& b) {
        return manhattan_distance(head, a) < manhattan_distance(head, b);
    });
    auto path = bfs(head, nearest_food, snake_body, obstacles, bounds);
    if (path.size() > 1) {
        auto next_pos = path[1];
        for (size_t d = 0; d < head.size(); ++d) {
            if (next_pos[d] != head[d]) {
                return {static_cast<int>(d), next_pos[d] - head[d]};
            }
        }
    }
    return {-1, -1};
}
