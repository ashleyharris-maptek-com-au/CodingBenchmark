# Chess Bot Implementation

## Overview

This C++ code implements a chess bot that takes a FEN string and a timeout as input and returns the best move in disambiguated algebraic notation.

* MSVC cl 19.50.35730 compiler

## Explanation

1. The code reads the timeout and FEN string from the input.
2. It creates a `Chess::Position` object from the FEN string.
3. It starts a search thread that performs a minimax search with alpha-beta pruning.
4. The search thread iterates over increasing depths until the timeout is reached.
5. The best move found so far is stored in the `bestMove` variable.
6. Once the timeout is reached, the search thread is stopped, and the best move is printed to the output.
