# Problem Understanding

The problem is to solve the Exact Cover problem. Given a universe of elements and a list of sets, we need to choose set indices such that every element is covered exactly once.

Key constraints and edge cases:

- The input format is given as `U S` followed by `S` lines, where each line represents a set containing space-separated element IDs.
- `U` is the number of elements in the universe (elements are `0..U-1`).
- `S` is the number of available sets.
- Each element in the universe should be covered exactly once.
- The output should be in the format `SOLUTION` followed by the indices of the chosen sets, or `NO SOLUTION` if no such combination exists.
- The output format is strict, and only the exact expected solution is accepted.
- The chosen indices should be valid and distinct.
- The input may contain duplicate sets or empty sets.

Output: `SOLUTION` followed by the indices of the chosen sets, or `NO SOLUTION`.

Subtle requirements:

def exact_cover(U, sets):
    def backtrack(index, covered, chosen):
        if len(covered) == U:
            return chosen
        if index == len(sets):
            return None
        # Try including the current set
        new_covered = covered.copy()
        valid = True
        for elem in sets[index]:
            if elem in new_covered:
                valid = False
                break
            new_covered.add(elem)
        if valid:
            result = backtrack(index + 1, new_covered, chosen + [index])
            if result is not None:
                return result
        # Try excluding the current set
        return backtrack(index + 1, covered, chosen)
    result = backtrack(0, set(), [])
    if result is None:
        return "NO SOLUTION"
    else:
        return "SOLUTION\n" + ' '.join(map(str, result))
