# Graph Coloring Problem Solution

## Overview

The following C++ code is designed to solve the Graph Coloring problem. It reads input from stdin, representing a graph and the number of colors to use, and outputs a valid coloring to stdout if one is found within the given time limit.

## Code

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <chrono>
#include <random>
#include <algorithm>

// Structure to represent a graph
struct Graph {
    int numVertices;
    int numEdges;
    int numColors;
    std::vector<std::vector<int>> adjacencyList;

    Graph(int numVertices, int numEdges, int numColors) 
        : numVertices(numVertices), numEdges(numEdges), numColors(numColors), adjacencyList(numVertices) {}
};

// Function to read graph from stdin
Graph readGraph() {
    int numVertices, numEdges, numColors;
    std::cin >> numVertices >> numEdges >> numColors;

    Graph graph(numVertices, numEdges, numColors);

    for (int i = 0; i < numEdges; ++i) {
        int u, v;
        std::cin >> u >> v;
        graph.adjacencyList[u].push_back(v);
        graph.adjacencyList[v].push_back(u);
    }

    return graph;
}

// Simple backtracking algorithm for smaller graphs
bool backtrack(Graph& graph, std::vector<int>& colors, int vertex = 0) {
    if (vertex == graph.numVertices) return true;

    std::vector<bool> used(graph.numColors, false);
    for (int neighbor : graph.adjacencyList[vertex]) {
        if (colors[neighbor] != -1) used[colors[neighbor]] = true;
    }

    for (int color = 0; color < graph.numColors; ++color) {
        if (!used[color]) {
            colors[vertex] = color;
            if (backtrack(graph, colors, vertex + 1)) return true;
            colors[vertex] = -1;
        }
    }

    return false;
}

// More efficient algorithm for larger graphs using a random greedy approach
void greedyColoring(Graph& graph, std::vector<int>& colors) {
    std::random_device rd;
    std::mt19937 gen(rd());
    std::vector<int> vertices(graph.numVertices);
    std::iota(vertices.begin(), vertices.end(), 0);
    std::shuffle(vertices.begin(), vertices.end(), gen);

    for (int vertex : vertices) {
        std::vector<bool> used(graph.numColors, false);
        for (int neighbor : graph.adjacencyList[vertex]) {
            if (colors[neighbor] != -1) used[colors[neighbor]] = true;
        }

        int color = 0;
        while (color < graph.numColors && used[color]) ++color;
        if (color < graph.numColors) colors[vertex] = color;
    }
}

int main() {
    auto start = std::chrono::high_resolution_clock::now();

    Graph graph = readGraph();
    std::vector<int> colors(graph.numVertices, -1);

    // Adaptive strategy based on graph size
    if (graph.numVertices <= 1000) {
        if (!backtrack(graph, colors)) {
            std::cerr << "Failed to find a valid coloring using backtracking." << std::endl;
            return 1;
        }
    } else {
        greedyColoring(graph, colors);
    }

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::seconds>(end - start).count();

    // Validate the coloring
    bool valid = true;
    for (int i = 0; i < graph.numVertices; ++i) {
        if (colors[i] == -1) {
            valid = false;
            break;
        }
        for (int neighbor : graph.adjacencyList[i]) {
            if (colors[i] == colors[neighbor]) {
                valid = false;
                break;
            }
        }
        if (!valid) break;
    }

    if (!valid) {
        std::cerr << "Invalid coloring found." << std::endl;
        return 1;
    }

    if (duration > 300) { // 5 minutes in seconds
        std::cerr << "Coloring found but exceeded time limit." << std::endl;
        return 1;
    }

    // Output the coloring
    for (int color : colors) {
        std::cout << color << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

## Explanation

1. **Graph Representation**: The graph is represented using an adjacency list for efficient neighbor lookup.
2. **Input/Output**: The program reads from stdin and writes to stdout as per the problem requirements.
3. **Adaptive Strategy**: For smaller graphs (<= 1000 vertices), a simple backtracking algorithm is used. For larger graphs, a random greedy coloring approach is employed to find a valid coloring within the time limit.
4. **Validation**: After obtaining a coloring, the program checks its validity by ensuring no two adjacent vertices have the same color and all vertices are colored.
5. **Time Limit**: The program checks if the coloring was found within the 5-minute time limit.

```bash
# Using g++
g++ -std=c++17 graph_coloring.cpp -o graph_coloring

cl.exe /std:c++17 graph_coloring.cpp /Fe:graph_coloring.exe
```

