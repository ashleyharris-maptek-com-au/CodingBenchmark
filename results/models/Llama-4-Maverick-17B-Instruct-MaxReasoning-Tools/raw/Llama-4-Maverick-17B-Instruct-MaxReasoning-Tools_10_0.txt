# Rectangle Bin Packing Problem Solver

## Overview

This C++ program solves the 2D Cutting Stock Problem (Rectangle Bin Packing) by minimizing the number of fixed-size large 2D boards purchased to accommodate a given list of rectangles. The algorithm is designed to be scalable and performant, handling problem sizes from trivial to ludicrous scale within a 30-second time limit.

## Algorithm

The solution employs a First-Fit Decreasing Height (FFDH) algorithm with rectangle rotation, a heuristic approach suitable for large-scale problems. The rectangles are first sorted by their areas in descending order. Then, they are iteratively placed on the boards using the FFDH strategy, which involves scanning the boards from left to right and bottom to top to find the first available position that can accommodate the rectangle.

## Implementation

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

// Structure to represent a rectangle
struct Rectangle {
    int width, height;
    int boardIndex, x, y;
    bool rotated;
};

// Structure to represent a board with its available skyline
struct Board {
    int width, height;
    std::vector<int> skyline;

    Board(int w, int h) : width(w), height(h), skyline(w, 0) {}
};

// Comparison function for sorting rectangles by area in descending order
bool compareRectangles(const Rectangle& a, const Rectangle& b) {
    return (a.width * a.height) > (b.width * b.height);
}

// Function to check if a rectangle can be placed at a given position on a board
bool canPlaceRectangle(const Board& board, int x, int y, int w, int h) {
    if (x + w > board.width || y + h > board.height) {
        return false;
    }
    for (int i = x; i < x + w; ++i) {
        if (board.skyline[i] > y) {
            return false;
        }
    }
    return true;
}

// Function to place a rectangle on a board and update the skyline
void placeRectangle(Board& board, Rectangle& rect, int x, int y, bool rotated) {
    int w = rotated ? rect.height : rect.width;
    int h = rotated ? rect.width : rect.height;
    rect.boardIndex = board.skyline.size() > board.width ? 0 : board.skyline.size(); // Assuming boards are indexed starting from 0
    rect.x = x;
    rect.y = y;
    rect.rotated = rotated;
    for (int i = x; i < x + w; ++i) {
        board.skyline[i] = y + h;
    }
}

// Main function to solve the rectangle bin packing problem
int main() {
    int N, boardWidth, boardHeight;
    std::cin >> N >> boardWidth >> boardHeight;

    std::vector<Rectangle> rectangles(N);
    for (int i = 0; i < N; ++i) {
        std::cin >> rectangles[i].width >> rectangles[i].height;
    }

    // Sort rectangles by area in descending order
    std::sort(rectangles.begin(), rectangles.end(), compareRectangles);

    std::vector<Board> boards;
    boards.emplace_back(boardWidth, boardHeight); // Start with one board

    for (auto& rect : rectangles) {
        bool placed = false;
        for (auto& board : boards) {
            // Try to place the rectangle without rotation
            for (int x = 0; x <= board.width - rect.width; ++x) {
                int y = *std::max_element(board.skyline.begin() + x, board.skyline.begin() + x + rect.width);
                if (canPlaceRectangle(board, x, y, rect.width, rect.height)) {
                    placeRectangle(board, rect, x, y, false);
                    placed = true;
                    break;
                }
            }
            if (placed) break;

            // Try to place the rectangle with rotation
            for (int x = 0; x <= board.width - rect.height; ++x) {
                int y = *std::max_element(board.skyline.begin() + x, board.skyline.begin() + x + rect.height);
                if (canPlaceRectangle(board, x, y, rect.height, rect.width)) {
                    placeRectangle(board, rect, x, y, true);
                    placed = true;
                    break;
                }
            }
            if (placed) break;
        }

        if (!placed) {
            // If the rectangle cannot be placed on any existing board, create a new board
            boards.emplace_back(boardWidth, boardHeight);
            int x = 0;
            int y = 0;
            placeRectangle(boards.back(), rect, x, y, false); // Try without rotation first
            if (rect.x != x || rect.y != y) { // If not placed, try with rotation
                placeRectangle(boards.back(), rect, x, y, true);
            }
        }
    }

    // Output the number of boards used and the placement of rectangles
    std::cout << boards.size() << std::endl;
    for (const auto& rect : rectangles) {
        std::cout << rect.boardIndex << " " << rect.x << " " << rect.y << " " << rect.rotated << std::endl;
    }

    return 0;
}
```

## Explanation

1.  The program starts by reading the number of rectangles `N`, the board width, and the board height from the standard input.
2.  It then reads the dimensions of `N` rectangles and stores them in a vector of `Rectangle` structures.
3.  The rectangles are sorted in descending order of their areas to prioritize larger rectangles.
4.  The program initializes a vector of `Board` structures, starting with a single board.
5.  It then iterates through the sorted rectangles, attempting to place each one on the existing boards without rotation and with rotation. The `canPlaceRectangle` function checks if a rectangle can be placed at a given position on a board, and the `placeRectangle` function updates the board's skyline accordingly.
6.  If a rectangle cannot be placed on any existing board, a new board is created, and the rectangle is placed on it.
7.  Finally, the program outputs the number of boards used and the placement details of each rectangle.
