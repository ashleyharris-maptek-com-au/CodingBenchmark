# Orbital Travelling Salesman Problem Solver

## Overview

This C# program solves the Orbital Travelling Salesman Problem for a given number of stations. It reads input from stdin, processes the data, and outputs the visitation order of station indices to stdout.

## Algorithm

The algorithm used is a hybrid approach that adapts based on the number of stations:

1.  For a small number of stations (2-5), it uses brute-force permutations to find the optimal solution.
2.  For a medium number of stations (6-10), it employs a nearest neighbor (NN) heuristic with some optimization.
3.  For a large number of stations (15-20), it uses a more complex algorithm involving the Christofides algorithm and 2-opt optimization.
4.  For an extreme number of stations (50-100), it utilizes a simplified Christofides algorithm with a more efficient nearest neighbor search.

                }
            }

            route[i] = nearestNeighbor - 1; // Adjust index
            visited[nearestNeighbor] = true;
            currentStation = nearestNeighbor;
        }

        return route;
    }

    private static double CalculateRouteDeltaV(int[] route, double[,] deltaVMatrix)
    {
        var deltaV = 0.0;
        var currentStation = 0; // Start at the initial orbit

        foreach (var station in route)
        {
            deltaV += deltaVMatrix[currentStation, station + 1]; // Adjust index
            currentStation = station + 1;

    private static IEnumerable<int[]> Permutations(int[] array)
