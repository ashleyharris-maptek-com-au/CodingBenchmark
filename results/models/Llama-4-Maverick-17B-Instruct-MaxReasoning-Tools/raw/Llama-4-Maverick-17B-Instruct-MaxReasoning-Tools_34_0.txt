**Capacitated Vehicle Routing Problem (CVRP) Solution**
======================================================

This Python code solves the CVRP using a simple Clarke-Wright Savings heuristic.

### Code

```python
import sys
import math

def distance(x1, y1, x2, y2):
    """Calculate Euclidean distance between two points."""
    return math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)

def read_input():
    """Read CVRP instance from stdin."""
    N, K, CAPACITY = map(int, sys.stdin.readline().split())
    depot_x, depot_y = map(float, sys.stdin.readline().split())
    customers = []
    for _ in range(N):
        x, y, demand = map(float, sys.stdin.readline().split())
        customers.append((x, y, demand))
    return N, K, CAPACITY, depot_x, depot_y, customers

def clarke_wright_savings(N, K, CAPACITY, depot_x, depot_y, customers):
    """Clarke-Wright Savings heuristic for CVRP."""
    # Initialize routes and distances
    routes = [[i] for i in range(N)]
    demands = [customers[i][2] for i in range(N)]
    savings = []
    for i in range(N):
        for j in range(i + 1, N):
            saving = distance(depot_x, depot_y, customers[i][0], customers[i][1]) + \
                     distance(depot_x, depot_y, customers[j][0], customers[j][1]) - \
                     distance(customers[i][0], customers[i][1], customers[j][0], customers[j][1])
            savings.append((saving, i, j))
    savings.sort(reverse=True)

    # Merge routes based on savings
    merged_routes = []
    for saving, i, j in savings:
        route_i = next((route for route in routes if i in route), None)
        route_j = next((route for route in routes if j in route), None)
        if route_i != route_j and route_i is not None and route_j is not None:
            demand_i = sum(demands[k] for k in route_i)
            demand_j = sum(demands[k] for k in route_j)
            if demand_i + demand_j <= CAPACITY:
                merged_route = route_i + route_j
                routes.remove(route_i)
                routes.remove(route_j)
                routes.append(merged_route)

    # Limit number of routes to K
    routes.sort(key=len, reverse=True)
    routes = routes[:K]
    remaining_customers = set(range(N)) - set.union(*[set(route) for route in routes])
    for customer in remaining_customers:
        # Find the route with the most available capacity
        available_capacities = [CAPACITY - sum(demands[k] for k in route) for route in routes]
        idx = available_capacities.index(max(available_capacities))
        routes[idx].append(customer)

    return routes

def calculate_total_distance(routes, depot_x, depot_y, customers):
    """Calculate total distance of the routes."""
    total_distance = 0
    for route in routes:
        total_distance += distance(depot_x, depot_y, customers[route[0]][0], customers[route[0]][1])
        for i in range(len(route) - 1):
            total_distance += distance(customers[route[i]][0], customers[route[i]][1],
                                       customers[route[i + 1]][0], customers[route[i + 1]][1])
        total_distance += distance(customers[route[-1]][0], customers[route[-1]][1], depot_x, depot_y)
    return total_distance

def output_routes(routes, total_distance):
    """Output routes to stdout."""
    print(total_distance)
    print(len(routes))
    for route in routes:
        print(' '.join(map(str, route)))

def main():
    N, K, CAPACITY, depot_x, depot_y, customers = read_input()
    routes = clarke_wright_savings(N, K, CAPACITY, depot_x, depot_y, customers)
    total_distance = calculate_total_distance(routes, depot_x, depot_y, customers)
    output_routes(routes, total_distance)

if __name__ == '__main__':
    main()
```

### Explanation

1. The code reads the CVRP instance from stdin using the `read_input` function.
2. The Clarke-Wright Savings heuristic is implemented in the `clarke_wright_savings` function, which merges routes based on savings.
3. The `calculate_total_distance` function calculates the total distance of the routes.
4. The `output_routes` function outputs the routes to stdout in the required format.
5. The `main` function orchestrates the entire process.

### Usage

To run the code, save it to a file (e.g., `cvrp.py`) and execute it using Python (e.g., `python cvrp.py`). Provide the CVRP instance as input through stdin. The output will be written to stdout.

Example usage:
```bash
$ python cvrp.py < input.txt > output.txt
```
Replace `input.txt` with your CVRP instance file and `output.txt` with the desired output file.
