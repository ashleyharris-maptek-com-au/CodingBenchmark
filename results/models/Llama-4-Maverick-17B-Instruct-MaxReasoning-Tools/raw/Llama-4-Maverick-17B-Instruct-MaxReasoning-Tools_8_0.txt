# Maze Solver in Rust

## Overview

The following Rust program is designed to solve mazes of varying complexity, from 5x5 to 50000x50000, using a breadth-first search (BFS) algorithm. BFS is suitable for this task as it is guaranteed to find the shortest path in an unweighted graph, which a maze can be represented as.

## Code

```rust
use std::collections::{VecDeque, HashSet};
use std::io::{self, BufRead};

#[derive(Debug, PartialEq, Eq, Clone, Copy, Hash)]
struct Coord {
    x: usize,
    y: usize,
}

impl Coord {
    fn new(x: usize, y: usize) -> Self {
        Coord { x, y }
    }
}

fn main() {
    let stdin = io::stdin();
    let mut lines = stdin.lock().lines().map(|l| l.unwrap());

    // Read the height and width of the maze
    let (height, width) = {
        let mut parts = lines.next().unwrap().split_whitespace();
        let height: usize = parts.next().unwrap().parse().unwrap();
        let width: usize = parts.next().unwrap().parse().unwrap();
        (height, width)
    };

    // Read the maze into a 2D vector
    let mut maze = Vec::with_capacity(height);
    let mut start = None;
    let mut end = None;
    for y in 0..height {
        let line = lines.next().unwrap();
        let mut row = Vec::with_capacity(width);
        for (x, c) in line.chars().enumerate() {
            match c {
                'A' => {
                    start = Some(Coord::new(x, y));
                    row.push(' ');
                }
                'B' => {
                    end = Some(Coord::new(x, y));
                    row.push(' ');
                }
                _ => row.push(c),
            }
        }
        maze.push(row);
    }

    // Check if start and end were found
    let start = start.expect("Start position 'A' not found");
    let end = end.expect("End position 'B' not found");

    // Perform BFS to find the path
    let path = bfs(&maze, start, end);

    // Output the path if found
    if let Some(path) = path {
        println!("{}", path.len());
        for coord in path {
            println!("{} {}", coord.x, coord.y);
        }
    } else {
        println!("0");
    }
}

fn bfs(maze: &Vec<Vec<char>>, start: Coord, end: Coord) -> Option<Vec<Coord>> {
    let height = maze.len();
    let width = maze[0].len();

    // Directions to explore: up, down, left, right
    let directions = [(0, -1), (0, 1), (-1, 0), (1, 0)];

    // Queue for BFS, contains cells in the form (coord, path)
    let mut queue = VecDeque::new();
    queue.push_back((start, vec![start]));

    // Set to keep track of visited cells
    let mut visited = HashSet::new();
    visited.insert(start);

    while let Some((current, path)) = queue.pop_front() {
        if current == end {
            return Some(path);
        }

        for &(dx, dy) in &directions {
            let x = current.x as isize + dx;
            let y = current.y as isize + dy;

            if x >= 0 && x < width as isize && y >= 0 && y < height as isize {
                let x = x as usize;
                let y = y as usize;
                let next = Coord::new(x, y);

                if !visited.contains(&next) && maze[y][x] != '#' {
                    let mut new_path = path.clone();
                    new_path.push(next);
                    queue.push_back((next, new_path));
                    visited.insert(next);
                }
            }
        }
    }

    None
}
```

## Explanation

1. The program reads the height and width of the maze from the first line of input.
2. It then reads the maze into a 2D vector, replacing 'A' and 'B' with spaces and storing their coordinates.
3. The `bfs` function performs a breadth-first search to find the shortest path from 'A' to 'B'.
4. It uses a queue to keep track of cells to visit next and a set to avoid revisiting cells.
5. Once the goal is reached, the path is returned and printed out.

## Notes

- The program assumes that the input is well-formed and does not contain any invalid characters or maze sizes.
- It uses a BFS algorithm, which is suitable for finding the shortest path in an unweighted graph like a maze.
- The use of a `HashSet` for keeping track of visited cells ensures that the algorithm does not revisit the same cell, which is crucial for performance, especially in large mazes.
- The program is designed to work with mazes of varying sizes, from small to very large (up to 50000x50000).
