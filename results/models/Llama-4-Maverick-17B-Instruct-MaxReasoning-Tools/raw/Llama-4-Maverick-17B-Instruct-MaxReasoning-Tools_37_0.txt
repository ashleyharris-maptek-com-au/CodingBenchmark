# Directed Feedback Vertex Set Problem Solution

The Directed Feedback Vertex Set problem is a well-known NP-hard problem. We will use a brute-force approach with some optimizations to solve it.

## Code

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;

public class DirectedFeedbackVertexSet
{
    private static bool IsAcyclic(bool[][] graph, bool[] removed)
    {
        int n = graph.Length;
        int[] inDegree = new int[n];

        // Calculate in-degree of each vertex
        for (int i = 0; i < n; i++)
        {
            if (!removed[i])
            {
                foreach (int neighbor in Enumerable.Range(0, n).Where(j => graph[i][j]))
                {
                    if (!removed[neighbor])
                    {
                        inDegree[neighbor]++;
                    }
                }
            }
        }

        // Initialize queue with vertices having in-degree 0
        Queue<int> queue = new Queue<int>(Enumerable.Range(0, n).Where(i => !removed[i] && inDegree[i] == 0));

        int visitedCount = 0;
        while (queue.Count > 0)
        {
            int vertex = queue.Dequeue();
            visitedCount++;

            foreach (int neighbor in Enumerable.Range(0, n).Where(j => graph[vertex][j]))
            {
                if (!removed[neighbor])
                {
                    inDegree[neighbor]--;
                    if (inDegree[neighbor] == 0)
                    {
                        queue.Enqueue(neighbor);
                    }
                }
            }
        }

        // If all non-removed vertices are visited, then the graph is acyclic
        return visitedCount == Enumerable.Range(0, n).Count(i => !removed[i]);
    }

    private static List<int> FindMinFeedbackVertexSet(bool[][] graph)
    {
        int n = graph.Length;
        int minSize = n;
        List<int> minSet = new List<int>(n);

        // Iterate over all possible subsets of vertices
        for (int mask = 0; mask < (1 << n); mask++)
        {
            bool[] removed = new bool[n];
            int count = 0;

            // Create a subset of vertices to remove based on the current mask
            for (int i = 0; i < n; i++)
            {
                if ((mask & (1 << i)) != 0)
                {
                    removed[i] = true;
                    count++;
                }
            }

            // Check if removing the current subset makes the graph acyclic
            if (IsAcyclic(graph, removed))
            {
                // Update the minimum-size set if the current subset is smaller
                if (count < minSize)
                {
                    minSize = count;
                    minSet = Enumerable.Range(0, n).Where(i => removed[i]).ToList();
                }
            }
        }

        return minSet;
    }

    public static void Main(string[] args)
    {
        using (StreamReader reader = new StreamReader(Console.OpenStandardInput()))
        using (StreamWriter writer = new StreamWriter(Console.OpenStandardOutput()))
        {
            string[] line = reader.ReadLine().Split();
            int n = int.Parse(line[0]);
            int m = int.Parse(line[1]);

            bool[][] graph = new bool[n][];

            for (int i = 0; i < n; i++)
            {
                graph[i] = new bool[n];
            }

            for (int i = 0; i < m; i++)
            {
                line = reader.ReadLine().Split();
                int u = int.Parse(line[0]);
                int v = int.Parse(line[1]);

                graph[u][v] = true;
            }

            List<int> feedbackVertexSet = FindMinFeedbackVertexSet(graph);

            writer.WriteLine(feedbackVertexSet.Count);
            writer.WriteLine(string.Join(" ", feedbackVertexSet));
        }
    }
}
```

## Explanation

1.  The provided C# code solves the Directed Feedback Vertex Set problem.
2.  The `IsAcyclic` method checks whether a given graph is acyclic after removing a subset of vertices.
3.  The `FindMinFeedbackVertexSet` method iterates over all possible subsets of vertices and uses the `IsAcyclic` method to find the minimum-size subset that makes the graph acyclic.
4.  In the `Main` method, the code reads the input graph from the standard input, constructs an adjacency matrix representation of the graph, and calls `FindMinFeedbackVertexSet` to compute the minimum feedback vertex set.
5.  The result is then written to the standard output in the required format.

## Time Complexity

The time complexity of this solution is O(2^n \* (n + m)), where n is the number of vertices and m is the number of edges. This is because we iterate over all possible subsets of vertices (2^n) and perform a topological sort (O(n + m)) for each subset.

## Note

This brute-force solution may not be efficient for very large graphs due to its exponential time complexity. For larger graphs, you may need to use more advanced algorithms or heuristics, such as approximation algorithms or parameterized algorithms. However, the given code should work within the test timeout for small to moderate-sized graphs.
