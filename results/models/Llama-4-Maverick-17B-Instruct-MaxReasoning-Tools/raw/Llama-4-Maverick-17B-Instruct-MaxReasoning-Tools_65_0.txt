# Mission Control Work Scheduler
## Overview

This Node.js TypeScript program schedules mission-control work across parallel workstations. It takes a JSON input containing the number of machines and a list of tasks with their dependencies, durations, deadlines, and weights. The program outputs a JSON document representing either a detailed schedule or a topological order of tasks.

## Code

```typescript
import * as fs from 'fs';

// Define the input and output data structures
interface Task {
  id: string;
  duration: number;
  deps: string[];
  deadline: number;
  weight: number;
}

interface InputData {
  machineCount: number;
  tasks: Task[];
}

interface ScheduleOutput {
  schedule: { id: string; start: number; machine: number }[];
}

interface OrderOutput {
  order: string[];
}

// Read input from stdin
const input: string = fs.readFileSync(0, 'utf8');
const data: InputData = JSON.parse(input);

// Process tasks
const taskMap: Map<string, Task> = new Map();
for (const task of data.tasks) {
  taskMap.set(task.id, task);
}

// Build graph and in-degree map
const graph: Map<string, string[]> = new Map();
const inDegree: Map<string, number> = new Map();
for (const task of data.tasks) {
  inDegree.set(task.id, task.deps.length);
  for (const dep of task.deps) {
    if (!graph.has(dep)) {
      graph.set(dep, []);
    }
    graph.get(dep)!.push(task.id);
  }
}

// Topological sorting using Kahn's algorithm
const order: string[] = [];
const queue: string[] = data.tasks.filter((task) => inDegree.get(task.id)! === 0).map((task) => task.id);
while (queue.length > 0) {
  const taskId = queue.shift()!;
  order.push(taskId);
  if (graph.has(taskId)) {
    for (const neighbor of graph.get(taskId)!) {
      const degree = inDegree.get(neighbor)! - 1;
      inDegree.set(neighbor, degree);
      if (degree === 0) {
        queue.push(neighbor);
      }
    }
  }
}

// Check for cycles
if (order.length !== data.tasks.length) {
  throw new Error("Cycle detected in the task dependencies");
}

// Output the topological order
const output: OrderOutput = { order };
console.log(JSON.stringify(output));
```

## Explanation

1. The program reads the input JSON from stdin and parses it into the `InputData` structure.
2. It builds a map of tasks for easy access and constructs a graph and in-degree map to represent the task dependencies.
3. The program performs a topological sort using Kahn's algorithm, which is suitable for large graphs and has a time complexity of O(|V| + |E|), where |V| is the number of tasks and |E| is the number of dependencies.
4. If a cycle is detected in the task dependencies, the program throws an error.
5. Finally, the program outputs the topological order of tasks as a JSON document.

## Notes

* This implementation focuses on scalability and avoids using browser APIs, network access, or external npm dependencies.
* The output is a topological order, which allows the grader to place tasks greedily in that order.
* The program does not generate a detailed schedule, as the grader can compute it from the topological order.
