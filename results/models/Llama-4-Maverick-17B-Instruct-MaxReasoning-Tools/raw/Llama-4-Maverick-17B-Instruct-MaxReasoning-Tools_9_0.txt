# 1D Cutting Stock Problem Solution in C#

## Problem Description

The 1D Cutting Stock Problem is a classic problem in Operations Research and Computer Science. Given a set of cuts (or demands) and a stock length, the goal is to assign these cuts to the minimum number of stocks such that the total length of cuts assigned to each stock does not exceed the stock length.

## Solution

The provided C# code solves the 1D Cutting Stock Problem using the First-Fit Decreasing (FFD) algorithm, a heuristic approach known for its efficiency and effectiveness in solving this problem.

### Code

```csharp
using System;
using System.Linq;

class CuttingStockProblem
{
    static void Main(string[] args)
    {
        // Read input from stdin
        string[] firstLine = Console.ReadLine().Split(' ');
        int numCuts = int.Parse(firstLine[0]);
        int stockLength = int.Parse(firstLine[1]);

        int[] cuts = Console.ReadLine().Split(' ').Select(int.Parse).ToArray();

        // Validate input
        if (cuts.Length != numCuts)
        {
            throw new ArgumentException("Number of cuts does not match the given count.");
        }

        if (cuts.Any(cut => cut > stockLength))
        {
            throw new ArgumentException("Cut length exceeds stock length.");
        }

        // Sort cuts in descending order
        Array.Sort(cuts);
        Array.Reverse(cuts);

        // Apply First-Fit Decreasing algorithm
        var (numStocks, stockAssignments) = Solve(cuts, stockLength);

        // Output the result to stdout
        Console.WriteLine(numStocks);
        foreach (var assignment in stockAssignments)
        {
            Console.WriteLine(string.Join(" ", assignment));
        }
    }

    static (int, int[][]) Solve(int[] cuts, int stockLength)
    {
        var stockAssignments = new System.Collections.Generic.List<int>[cuts.Length];
        int numStocks = 0;

        foreach ((int cut, int index) in cuts.Select((cut, index) => (cut, index)))
        {
            bool assigned = false;
            for (int i = 0; i < numStocks; i++)
            {
                if (stockAssignments[i] == null)
                {
                    stockAssignments[i] = new System.Collections.Generic.List<int>();
                }

                int totalLength = stockAssignments[i].Sum(c => cuts[c]);
                if (totalLength + cut <= stockLength)
                {
                    stockAssignments[i].Add(index);
                    assigned = true;
                    break;
                }
            }

            if (!assigned)
            {
                if (numStocks == stockAssignments.Length)
                {
                    // Resize the array if necessary
                    var newStockAssignments = new System.Collections.Generic.List<int>[stockAssignments.Length * 2];
                    Array.Copy(stockAssignments, newStockAssignments, stockAssignments.Length);
                    stockAssignments = newStockAssignments;
                }

                stockAssignments[numStocks] = new System.Collections.Generic.List<int> { index };
                numStocks++;
            }
        }

        // Trim the stockAssignments array to the actual number of stocks used
        var trimmedStockAssignments = new int[numStocks][];
        for (int i = 0; i < numStocks; i++)
        {
            trimmedStockAssignments[i] = stockAssignments[i].ToArray();
        }

        return (numStocks, trimmedStockAssignments);
    }
}
```

### Explanation

1.  The code starts by reading the input from `stdin`, parsing the number of cuts and the stock length, and then reading the cut lengths.
2.  It validates the input to ensure that the number of cuts matches the given count and that no cut length exceeds the stock length.
3.  The cuts are sorted in descending order to apply the First-Fit Decreasing algorithm.
4.  The `Solve` method implements the FFD algorithm, iterating through the sorted cuts and assigning each cut to the first stock that has enough remaining length. If no such stock exists, a new stock is used.
5.  The result, including the number of stocks used and the cut indices assigned to each stock, is output to `stdout`.

### Efficiency

The provided C# code is designed to handle a large number of cuts efficiently. The time complexity of the FFD algorithm is O(n log n) due to the sorting step, where n is the number of cuts. The subsequent assignment step has a time complexity of O(n \* m), where m is the number of stocks used. However, in practice, m is typically much smaller than n, making the overall algorithm efficient for large inputs.

The code also takes advantage of the available memory (127.87 GB) to handle a large number of cuts. It dynamically resizes the `stockAssignments` array as needed to accommodate the number of stocks used.

Given the computational resources available (64-core CPU, AVX, and AVX2 support), the code is well-suited to handle the 1D Cutting Stock Problem within the specified time limit of 5 minutes, even for millions of cuts.
