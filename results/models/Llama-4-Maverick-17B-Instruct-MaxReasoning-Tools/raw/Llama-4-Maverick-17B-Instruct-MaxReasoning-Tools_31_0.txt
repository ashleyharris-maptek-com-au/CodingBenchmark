# Subset Sum Problem Solver in Rust

This code solves the Subset Sum problem using a combination of dynamic programming and bit manipulation. For larger instances, it employs a meet-in-the-middle approach to improve performance.

## Code

```rust
use std::collections::HashSet;
use std::io::{self, BufRead, BufReader};
use std::thread;
use std::sync::mpsc;

fn main() {
    let stdin = io::stdin();
    let mut reader = BufReader::new(stdin.lock());

    let mut line = String::new();
    reader.read_line(&mut line).unwrap();
    let mut parts = line.trim().split_whitespace();
    let num_numbers: usize = parts.next().unwrap().parse().unwrap();
    let target: i64 = parts.next().unwrap().parse().unwrap();

    line.clear();
    reader.read_line(&mut line).unwrap();
    let numbers: Vec<i64> = line.trim().split_whitespace()
        .map(|x| x.parse().unwrap())
        .collect();

    if num_numbers <= 30 {
        // For small instances, use brute force
        brute_force(&numbers, target);
    } else {
        // For larger instances, use meet-in-the-middle approach
        meet_in_the_middle(&numbers, target);
    }
}

fn brute_force(numbers: &Vec<i64>, target: i64) {
    let mut mask = 0;
    let n = numbers.len();
    for i in 0..(1 << n) {
        let mut sum = 0;
        let mut indices = Vec::new();
        for j in 0..n {
            if (i & (1 << j)) != 0 {
                sum += numbers[j];
                indices.push(j);
            }
        }
        if sum == target {
            println!("YES");
            println!("{}", indices.iter().map(|x| x.to_string()).collect::<Vec<String>>().join(" "));
            return;
        }
    }
    println!("NO");
}

fn meet_in_the_middle(numbers: &Vec<i64>, target: i64) {
    let n = numbers.len();
    let mid = n / 2;

    let (tx, rx) = mpsc::channel();
    let numbers1 = numbers[..mid].to_vec();
    let numbers2 = numbers[mid..].to_vec();

    thread::spawn(move || {
        let mut sums = HashSet::new();
        for mask in 0..(1 << numbers1.len()) {
            let mut sum = 0;
            for j in 0..numbers1.len() {
                if (mask & (1 << j)) != 0 {
                    sum += numbers1[j];
                }
            }
            sums.insert(sum);
        }
        tx.send(sums).unwrap();
    });

    let mut sums2 = Vec::new();
    for mask in 0..(1 << numbers2.len()) {
        let mut sum = 0;
        let mut indices = Vec::new();
        for j in 0..numbers2.len() {
            if (mask & (1 << j)) != 0 {
                sum += numbers2[j];
                indices.push(j + mid);
            }
        }
        sums2.push((sum, indices));
    }

    let sums1 = rx.recv().unwrap();
    for (sum2, indices2) in sums2 {
        let complement = target - sum2;
        if sums1.contains(&complement) {
            for mask in 0..(1 << numbers1.len()) {
                let mut sum1 = 0;
                let mut indices1 = Vec::new();
                for j in 0..numbers1.len() {
                    if (mask & (1 << j)) != 0 {
                        sum1 += numbers1[j];
                        indices1.push(j);
                    }
                }
                if sum1 == complement {
                    println!("YES");
                    indices1.extend(indices2);
                    println!("{}", indices1.iter().map(|x| x.to_string()).collect::<Vec<String>>().join(" "));
                    return;
                }
            }
        }
    }
    println!("NO");
}
```

## Explanation

The code reads input from stdin and writes output to stdout. It first determines the number of elements and the target sum, then reads the elements.

For small instances (<= 30 elements), it uses a brute force approach to check all possible subsets.

For larger instances, it employs a meet-in-the-middle approach. The elements are divided into two halves, and the sums of all possible subsets of the first half are precomputed and stored in a HashSet. Then, for each subset of the second half, it checks if the complement (target sum minus the sum of the current subset) is present in the precomputed sums. If a match is found, it reconstructs the indices of the elements in the subset that sums to the target.

The code uses multi-threading to improve performance by computing the sums of subsets of the first half in a separate thread.

## Compilation and Execution

To compile the code, save it to a file (e.g., `subset_sum.rs`) and run the following command:

```bash
rustc subset_sum.rs
```

To execute the code, run the following command:

```bash
./subset_sum < input.txt
```

Replace `input.txt` with the file containing the input data.

## Notes

* The code assumes that the input data is in the correct format.
* The code uses a HashSet to store the precomputed sums, which provides an average-case time complexity of O(1) for lookup operations.
* The meet-in-the-middle approach reduces the time complexity from O(2^n) to O(2^(n/2)), making it more efficient for larger instances.
