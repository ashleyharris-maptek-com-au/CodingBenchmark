# Maximum Independent Set Problem Solution

## Overview

The Maximum Independent Set problem is an NP-hard problem that involves finding the largest set of vertices in an undirected graph such that no two chosen vertices share an edge. Here, we provide a C++ solution using a brute-force approach with bit manipulation to generate all possible subsets of vertices and check if they form an independent set.

## Code

```cpp
#include <iostream>
#include <vector>
#include <cstdint>
#include <algorithm>
#include <stdexcept>

// Structure to represent an undirected graph using adjacency list
class Graph {
public:
    Graph(int n) : numVertices(n), adjList(n) {}

    void addEdge(int u, int v) {
        adjList[u].push_back(v);
        adjList[v].push_back(u);
    }

    bool isIndependentSet(uint64_t subset) const {
        for (int i = 0; i < numVertices; ++i) {
            if ((subset & (1ULL << i)) != 0) {
                for (const auto& neighbor : adjList[i]) {
                    if ((subset & (1ULL << neighbor)) != 0) {
                        return false;
                    }
                }
            }
        }
        return true;
    }

    int countSetBits(uint64_t n) const {
        int count = 0;
        while (n) {
            count += n & 1;
            n >>= 1;
        }
        return count;
    }

    std::vector<int> getMaxIndependentSet() const {
        uint64_t maxSubset = 0;
        int maxSize = 0;

        // Iterate over all possible subsets
        for (uint64_t subset = 0; subset < (1ULL << numVertices); ++subset) {
            if (isIndependentSet(subset)) {
                int size = countSetBits(subset);
                if (size > maxSize) {
                    maxSize = size;
                    maxSubset = subset;
                }
            }
        }

        // Extract vertices from the maximum independent set
        std::vector<int> maxIndependentSet;
        for (int i = 0; i < numVertices; ++i) {
            if ((maxSubset & (1ULL << i)) != 0) {
                maxIndependentSet.push_back(i);
            }
        }

        return maxIndependentSet;
    }

private:
    int numVertices;
    std::vector<std::vector<int>> adjList;
};

int main() {
    try {
        int n, m;
        std::cin >> n >> m;

        if (n < 0 || m < 0) {
            throw std::invalid_argument("Number of vertices and edges must be non-negative.");
        }

        Graph graph(n);

        for (int i = 0; i < m; ++i) {
            int u, v;
            std::cin >> u >> v;

            if (u < 0 || v < 0 || u >= n || v >= n) {
                throw std::out_of_range("Vertex index out of range.");
            }

            graph.addEdge(u, v);
        }

        std::vector<int> maxIndependentSet = graph.getMaxIndependentSet();

        // Output the size and vertices of the maximum independent set
        std::cout << maxIndependentSet.size() << std::endl;
        for (size_t i = 0; i < maxIndependentSet.size(); ++i) {
            std::cout << maxIndependentSet[i];
            if (i != maxIndependentSet.size() - 1) {
                std::cout << " ";
            }
        }
        std::cout << std::endl;

        return 0;
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << std::endl;
        return 1;
    }
}
```

## Explanation

1.  We define a `Graph` class to represent the undirected graph using an adjacency list.
2.  The `addEdge` method is used to add edges to the graph.
3.  The `isIndependentSet` method checks if a given subset of vertices forms an independent set by verifying that no two vertices in the subset share an edge.
4.  The `countSetBits` method counts the number of set bits in a given integer, representing the size of the subset.
5.  The `getMaxIndependentSet` method iterates over all possible subsets of vertices using bit manipulation and checks if they form an independent set. It keeps track of the maximum independent set found so far.
6.  In the `main` function, we read the input graph from `stdin`, construct the graph, and find the maximum independent set using the `getMaxIndependentSet` method.
7.  Finally, we output the size and vertices of the maximum independent set to `stdout`.

## Notes

*   This solution has an exponential time complexity due to the brute-force approach, which may not be suitable for very large graphs.
*   For larger graphs, more efficient algorithms or heuristics may be necessary to find a good approximate solution within a reasonable time limit.
