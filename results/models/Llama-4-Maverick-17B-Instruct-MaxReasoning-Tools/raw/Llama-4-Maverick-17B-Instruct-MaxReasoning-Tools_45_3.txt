To generate the SPIR-V binary as a hex string for the given task, we need to follow the SPIR-V specification and the details provided.

1. **Header Generation:**
   - Magic number: `03022307` (0x07230203 in little-endian)
   - Version: `00010000` (Version 1.0, 0x00010000)
   - Generator: `00000000` (Manual generation)
   - Bound: We'll need to calculate this based on the IDs used. Let's start with a simple shader and adjust accordingly.
   - Reserved: `00000000`

2. **Shader Instructions:**
   - The task is to pass through the per-vertex color directly with alpha 1.0.

Let's break down the steps and generate the SPIR-V instructions accordingly.

### Step 1: Header
First, let's start with the header. We'll initially set the bound to a reasonable value (e.g., 0x30) and adjust if necessary.


### Step 2: Capabilities and Extensions
We need to declare the Shader capability.

```hex

```

### Step 3: Memory Model
Declare the memory model as Logical with GLSL450.

```hex

00000000 // Addressing Model = Logical (0)

```

### Step 4: Entry Point and Execution Mode
Declare the entry point for the fragment shader and set the execution mode to OriginUpperLeft.

```hex
0f030000 // OpEntryPoint (15), WordCount = 3
04000000 // Execution Model = Fragment (4)
05000000 // Entry Point ID = %5
... // Name string (not counted in WordCount for OpEntryPoint, but for the string itself)
```

Let's simplify the name string for the entry point to "main". The null-terminated string "main" is `0x6d61696e`.

