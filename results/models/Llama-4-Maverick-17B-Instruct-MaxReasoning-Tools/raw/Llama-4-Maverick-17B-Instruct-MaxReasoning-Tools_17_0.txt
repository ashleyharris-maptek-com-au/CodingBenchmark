# 3D Bin Packing Problem Solution

## Overview

The following C# code solves the 3D Bin Packing problem by using a variant of the First-Fit Decreasing Height (FFDH) algorithm, adapted for 3D. The algorithm sorts the boxes by volume in descending order and then attempts to pack them into the container.

## Code

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

public class Box
{
    public int Index { get; set; }
    public int Width { get; set; }
    public int Height { get; set; }
    public int Depth { get; set; }

    public int Volume => Width * Height * Depth;

    public void Rotate()
    {
        var temp = Width;
        Width = Height;
        Height = Depth;
        Depth = temp;
    }

    public bool Fits(int containerWidth, int containerHeight, int containerDepth)
    {
        return Width <= containerWidth && Height <= containerHeight && Depth <= containerDepth;
    }
}

public class Placement
{
    public int X { get; set; }
    public int Y { get; set; }
    public int Z { get; set; }
    public Box Box { get; set; }
}

class Program
{
    static void Main(string[] args)
    {
        var input = Console.In.ReadToEnd().Split(new[] { Environment.NewLine }, StringSplitOptions.None);
        var containerParams = input[0].Split(' ').Select(int.Parse).ToArray();
        var N = containerParams[0];
        var containerWidth = containerParams[1];
        var containerHeight = containerParams[2];
        var containerDepth = containerParams[3];

        var boxes = new List<Box>();
        for (int i = 0; i < N; i++)
        {
            var boxDimensions = input[i + 1].Split(' ').Select(int.Parse).ToArray();
            var box = new Box { Index = i, Width = boxDimensions[0], Height = boxDimensions[1], Depth = boxDimensions[2] };
            boxes.Add(box);
        }

        // Sort boxes by volume in descending order
        boxes = boxes.OrderByDescending(b => b.Volume).ToList();

        var placements = new List<Placement>();
        var occupied = new bool[containerWidth, containerHeight, containerDepth];

        foreach (var box in boxes)
        {
            // Try different rotations of the box
            for (int rotation = 0; rotation < 6; rotation++)
            {
                if (box.Fits(containerWidth, containerHeight, containerDepth))
                {
                    var placement = FindPlacement(occupied, box, containerWidth, containerHeight, containerDepth);
                    if (placement != null)
                    {
                        placements.Add(placement);
                        MarkOccupied(occupied, placement);
                        break; // Move on to the next box
                    }
                }
                box.Rotate();
                if (rotation == 2) // After 3 rotations, swap width and depth to try different orientations
                {
                    var temp = box.Width;
                    box.Width = box.Depth;
                    box.Depth = temp;
                }
            }
        }

        Console.WriteLine(placements.Count);
        foreach (var placement in placements)
        {
            Console.WriteLine($"{placement.Box.Index} {placement.X} {placement.Y} {placement.Z}");
        }
    }

    static Placement FindPlacement(bool[,,] occupied, Box box, int containerWidth, int containerHeight, int containerDepth)
    {
        for (int x = 0; x <= containerWidth - box.Width; x++)
        {
            for (int y = 0; y <= containerHeight - box.Height; y++)
            {
                for (int z = 0; z <= containerDepth - box.Depth; z++)
                {
                    if (IsValidPlacement(occupied, x, y, z, box.Width, box.Height, box.Depth))
                    {
                        return new Placement { X = x, Y = y, Z = z, Box = box };
                    }
                }
            }
        }
        return null;
    }

    static bool IsValidPlacement(bool[,,] occupied, int x, int y, int z, int width, int height, int depth)
    {
        for (int i = x; i < x + width; i++)
        {
            for (int j = y; j < y + height; j++)
            {
                for (int k = z; k < z + depth; k++)
                {
                    if (occupied[i, j, k]) return false;
                }
            }
        }
        return true;
    }

    static void MarkOccupied(bool[,,] occupied, Placement placement)
    {
        for (int i = placement.X; i < placement.X + placement.Box.Width; i++)
        {
            for (int j = placement.Y; j < placement.Y + placement.Box.Height; j++)
            {
                for (int k = placement.Z; k < placement.Z + placement.Box.Depth; k++)
                {
                    occupied[i, j, k] = true;
                }
            }
        }
    }
}
```

## Explanation

1.  The code starts by reading the input from the standard input, parsing the container dimensions and the dimensions of the boxes.
2.  It sorts the boxes by their volume in descending order to prioritize packing larger boxes first.
3.  The algorithm then iterates over the sorted boxes and attempts to pack each one into the container.
4.  For each box, it tries different rotations to find a valid placement.
5.  The `FindPlacement` method checks for a valid placement by iterating over the container's volume and checking if the box can be placed at a given position without overlapping with already occupied space.
6.  If a valid placement is found, the box is marked as occupied in the `occupied` 3D array, and the placement is added to the list of placements.
7.  Finally, the code outputs the number of packed boxes and their corresponding placements.
