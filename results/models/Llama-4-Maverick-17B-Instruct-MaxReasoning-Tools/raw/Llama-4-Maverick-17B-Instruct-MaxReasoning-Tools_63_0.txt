# Robot Job Assignment

## Problem Statement

Assign warehouse pick jobs to robots based on the shortest grid walking distance.

## Solution

The following TypeScript program reads the input JSON from stdin, processes it, and outputs the assignments to stdout.

```typescript
import * as fs from 'fs';

// Define the input data structure
interface Robot {
  id: number;
  x: number;
  y: number;
}

interface Job {
  id: number;
  x: number;
  y: number;
  priority: number;
}

interface InputData {
  grid: string[];
  robots: Robot[];
  jobs: Job[];
}

// Define the output data structure
interface OutputData {
  assignments: number[][];
}

// Function to calculate Manhattan distance between two points
function manhattanDistance(x1: number, y1: number, x2: number, y2: number): number {
  return Math.abs(x1 - x2) + Math.abs(y1 - y2);
}

// Function to check if a cell is valid (not blocked and within grid bounds)
function isValidCell(grid: string[], x: number, y: number): boolean {
  return x >= 0 && x < grid.length && y >= 0 && y < grid[0].length && grid[x][y] !== '#';
}

// Function to calculate the shortest distance between a robot and a job using BFS
function calculateDistance(grid: string[], robotX: number, robotY: number, jobX: number, jobY: number): number {
  const queue: [number, number, number][] = [[robotX, robotY, 0]];
  const visited: boolean[][] = Array(grid.length).fill(false).map(() => Array(grid[0].length).fill(false));
  visited[robotX][robotY] = true;

  while (queue.length > 0) {
    const [x, y, distance] = queue.shift()!;
    if (x === jobX && y === jobY) {
      return distance;
    }

    // Explore neighbors
    for (const [dx, dy] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
      const nx = x + dx;
      const ny = y + dy;
      if (isValidCell(grid, nx, ny) && !visited[nx][ny]) {
        queue.push([nx, ny, distance + 1]);
        visited[nx][ny] = true;
      }
    }
  }

  // If there's no path, return infinity
  return Infinity;
}

// Main function to assign jobs to robots
function assignJobs(data: InputData): OutputData {
  const assignments: number[][] = Array(data.robots.length).fill(0).map(() => []);

  // Sort jobs by priority in descending order
  data.jobs.sort((a, b) => b.priority - a.priority);

  for (const job of data.jobs) {
    let closestRobot: number | null = null;
    let minDistance = Infinity;

    for (const robot of data.robots) {
      const distance = calculateDistance(data.grid, robot.x, robot.y, job.x, job.y);
      if (distance < minDistance) {
        minDistance = distance;
        closestRobot = robot.id;
      }
    }

    if (closestRobot !== null) {
      assignments[closestRobot].push(job.id);
    }
  }

  return { assignments };
}

// Read input from stdin
const input: string = fs.readFileSync(0, 'utf8');
const data: InputData = JSON.parse(input);

// Process the input data and generate output
const output: OutputData = assignJobs(data);

// Write output to stdout
console.log(JSON.stringify(output));
```

## Explanation

1. The program starts by reading the input JSON from stdin using `fs.readFileSync(0, 'utf8')`.
2. It then parses the input JSON into the `InputData` structure.
3. The `assignJobs` function is the main logic that assigns jobs to robots. It sorts the jobs by priority in descending order and then iterates over each job.
4. For each job, it finds the closest robot by calculating the shortest distance using BFS.
5. Once the closest robot is found, the job is assigned to that robot.
6. The assignments are stored in the `assignments` array, which is then returned as the output.
7. Finally, the output is stringified and written to stdout using `console.log`.

## Note

This implementation uses a greedy approach to assign jobs to robots based on the shortest distance. While this may not always result in the optimal solution, it is a reasonable heuristic for this problem. The BFS algorithm is used to calculate the shortest distance between a robot and a job, which is more efficient than using a more complex pathfinding algorithm like A\* for this particular problem.
