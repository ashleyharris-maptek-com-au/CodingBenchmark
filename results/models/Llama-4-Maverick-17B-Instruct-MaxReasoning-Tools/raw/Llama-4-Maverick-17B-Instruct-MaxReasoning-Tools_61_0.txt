# Delivery Route Planner

## Overview

This TypeScript program plans delivery routes for a fleet of vans. It takes a JSON input containing the depot location, the maximum number of vans, and a list of packages with their locations. The program outputs a JSON document describing the planned routes.

## Code

```typescript
// Import required modules
declare const require: any;
const fs = require('fs');

// Read input from stdin
const input: string = fs.readFileSync(0, 'utf8');
const data = JSON.parse(input);

// Define types
interface Package {
  id: string;
  x: number;
  y: number;
}

interface InputData {
  depot: [number, number];
  truckCount: number;
  packages: Package[];
}

interface Route {
  route: string[];
}

// Function to calculate the distance between two points
function distance(x1: number, y1: number, x2: number, y2: number): number {
  return Math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2);
}

// Function to solve the delivery route planning problem
function planDeliveryRoutes(data: InputData): { routes: string[][] } {
  const { depot, truckCount, packages } = data;
  const depotX = depot[0];
  const depotY = depot[1];

  // Sort packages by distance from the depot
  packages.sort((a, b) => {
    const distA = distance(depotX, depotY, a.x, a.y);
    const distB = distance(depotX, depotY, b.x, b.y);
    return distA - distB;
  });

  // Assign packages to routes
  const routes: string[][] = Array.from({ length: truckCount }, () => []);
  for (let i = 0; i < packages.length; i++) {
    const packageId = packages[i].id;
    const routeIndex = i % truckCount;
    routes[routeIndex].push(packageId);
  }

  return { routes };
}

// Plan delivery routes and output the result
const result = planDeliveryRoutes(data);
console.log(JSON.stringify(result));
```

## Explanation

1. The program reads the input JSON from stdin using `fs.readFileSync(0, 'utf8')`.
2. It parses the input JSON into a JavaScript object using `JSON.parse(input)`.
3. The `planDeliveryRoutes` function takes the input data and plans the delivery routes.
4. It sorts the packages by their distance from the depot.
5. The packages are then assigned to routes in a round-robin manner to distribute them evenly among the available vans.
6. The planned routes are returned as a JSON object with the format `{ routes: [[packageId, ...], ...] }`.
7. Finally, the result is stringified and printed to stdout using `console.log(JSON.stringify(result))`.

## Example Usage

To run this program, save it to a file (e.g., `deliveryRoutePlanner.ts`), compile it to JavaScript using the TypeScript compiler, and then run the resulting JavaScript file using Node.js.

```bash
# Compile TypeScript to JavaScript
tsc deliveryRoutePlanner.ts

# Run the program with sample input
node deliveryRoutePlanner.js < input.json
```

Replace `input.json` with your actual input file containing the depot location, truck count, and package information in the specified JSON format. The program will output the planned delivery routes in the required JSON format.
