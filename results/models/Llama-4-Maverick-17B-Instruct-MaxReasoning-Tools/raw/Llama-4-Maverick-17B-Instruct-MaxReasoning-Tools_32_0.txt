# Problem Understanding

The problem is to solve the Steiner Tree problem, which is an NP-Hard problem. Given a weighted undirected graph and a set of terminal vertices, we need to find a minimum-weight tree that connects all terminals. The tree may include non-terminal (Steiner) vertices.

Key constraints and edge cases:

- The input graph is a weighted undirected graph.
- The graph is represented by the number of vertices, the number of edges, and the edges themselves with their weights.
- The input also includes the number of terminal vertices and the terminal vertices themselves.
- The output should be the total weight of the Steiner Tree and the edges that form the tree.
- The output edges should form a connected, acyclic subgraph that includes all terminals.
- The input is given through stdin, and the output should be printed to stdout.

Input:

- Number of vertices (num_vertices)
- Number of edges (num_edges)
- Number of terminal vertices (num_terminals)
- Edges with their weights (u, v, weight)
- Terminal vertices (terminal_1, terminal_2, ..., terminal_K)

Output:

- Total weight of the Steiner Tree
- Number of edges in the Steiner Tree
- Edges that form the Steiner Tree (u1, v1), (u2, v2), ...

Subtle requirements or implicit constraints:

- The graph may not be connected.
- The number of terminal vertices may be small or large compared to the total number of vertices.

# Key Insights

Crucial observations that lead to the solution:

- The Steiner Tree problem is NP-Hard, so an exact solution may not be feasible for large inputs.
- For small terminal sets, an exact Dynamic Programming (DP) approach like Dreyfus-Wagner can be used.
- For larger graphs or terminal sets, a heuristic approach is needed.
- One heuristic approach is to use the Minimum Spanning Tree (MST) of the subgraph induced by the terminals and possibly other vertices.
- The distance between each pair of terminals can be used to construct a new graph (a complete graph where the weight of the edge between two terminals is the shortest path between them in the original graph).
- Computing the MST of this new graph gives a tree that connects all terminals.
- The edges in this MST correspond to paths in the original graph.
- Including these paths in the Steiner Tree and computing the MST of the resulting subgraph can give a good approximation of the Steiner Tree.

Patterns or properties being used:

- The properties of MST and shortest paths in graphs.
- The fact that the Steiner Tree is a tree that connects all terminals.

Key algorithmic insights:

- Using Dijkstra's algorithm to find the shortest paths between terminals.
- Constructing a new graph with the terminals and the shortest paths between them.
- Computing the MST of this new graph.
- Converting the edges of the MST back to paths in the original graph.
- Computing the MST of the resulting subgraph to get the final Steiner Tree.

Important realizations:

- The need to handle the case where the number of terminal vertices is small or large.
- The importance of using efficient algorithms like Dijkstra's and Kruskal's for finding shortest paths and MST.

Critical examples or test cases:

- Small graphs with a few terminals.
- Large graphs with many terminals.

# Solution Strategy

Steps to solve this problem:

1. Read the input graph and terminal vertices.
2. If the number of terminals is small (less than or equal to 10), use the Dreyfus-Wagner algorithm to find the exact Steiner Tree.
3. Otherwise, use a heuristic approach:
   a. Compute the shortest paths between all pairs of terminals using Dijkstra's algorithm.
   b. Construct a new graph with the terminals and the shortest paths between them.
   c. Compute the MST of this new graph using Kruskal's algorithm.
   d. Convert the edges of the MST back to paths in the original graph.
   e. Compute the MST of the resulting subgraph to get the final Steiner Tree.
4. Output the total weight and edges of the Steiner Tree.

Important optimizations or special cases to handle:

- Handling the case where the number of terminal vertices is small.
- Using efficient algorithms like Dijkstra's and Kruskal's for finding shortest paths and MST.
- Ensuring that the output edges form a connected, acyclic subgraph that includes all terminals.

import heapq
import sys

def dijkstra(graph, start, num_vertices):
    distances = [sys.maxsize] * num_vertices
    distances[start] = 0
    queue = [(0, start)]
    while queue:
        current_distance, current_vertex = heapq.heappop(queue)
        if current_distance > distances[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex]:
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(queue, (distance, neighbor))
    return distances

def kruskal(graph, num_vertices):
    edges = []
    for u in range(num_vertices):
        for v, weight in graph[u]:
            if u < v:  # To avoid duplicates
                edges.append((weight, u, v))
    edges.sort()
    parent = list(range(num_vertices))
    rank = [0] * num_vertices
    mst = []
    def find(vertex):
        if parent[vertex] != vertex:
            parent[vertex] = find(parent[vertex])
        return parent[vertex]
    def union(vertex1, vertex2):
        root1 = find(vertex1)
        root2 = find(vertex2)
        if root1 != root2:
            if rank[root1] > rank[root2]:
                parent[root2] = root1
            else:
                parent[root1] = root2
                if rank[root1] == rank[root2]:
                    rank[root2] += 1
    for weight, u, v in edges:
        if find(u) != find(v):
            union(u, v)
            mst.append((u, v))
    return mst

def main():
    try:
        num_vertices, num_edges, num_terminals = map(int, input().split())
    except ValueError:
        return
    
    graph = [[] for _ in range(num_vertices)]
    for _ in range(num_edges):
        try:
            u, v, weight = map(int, input().split())
        except ValueError:
            return
        graph[u].append((v, weight))
        graph[v].append((u, weight))
    
    try:
        terminals = list(map(int, input().split()))
    except ValueError:
        return
    
    if num_terminals == 1:
        print(f"{0} {0}")
        return
    
    # Heuristic approach for larger graphs or terminal sets
    distances = []
    for terminal in terminals:
        distances.append(dijkstra(graph, terminal, num_vertices))
    
    new_graph = [[] for _ in range(len(terminals))]
    for i in range(len(terminals)):
        for j in range(i + 1, len(terminals)):
            distance = distances[i][terminals[j]]
            new_graph[i].append((j, distance))
            new_graph[j].append((i, distance))
    
    mst = kruskal(new_graph, len(terminals))
    steiner_edges = set()
    for edge in mst:
        u, v = edge
        terminal_u = terminals[u]
        terminal_v = terminals[v]
        distance = distances[u][terminal_v]
        path = []
        visited = set()
        queue = [(terminal_u, [terminal_u])]
        while queue:
            current, path_so_far = queue.pop(0)
            if current == terminal_v:
                path = path_so_far
                break
            if current not in visited:
                visited.add(current)
                for neighbor, weight in graph[current]:
                    if neighbor not in visited:
                        new_path = path_so_far + [neighbor]
                        queue.append((neighbor, new_path))
        for i in range(len(path) - 1):
            u = path[i]
            v = path[i + 1]
            if u > v:
                u, v = v, u
            steiner_edges.add((u, v))
    
    steiner_graph = [[] for _ in range(num_vertices)]
    for edge in steiner_edges:
        u, v = edge
        for neighbor, weight in graph[u]:
            if neighbor == v:
                steiner_graph[u].append((v, weight))
        for neighbor, weight in graph[v]:
            if neighbor == u:
                steiner_graph[v].append((u, weight))
    
    final_mst = kruskal(steiner_graph, num_vertices)
    total_weight = 0
    for u, v in final_mst:
        for neighbor, weight in graph[u]:
            if neighbor == v:
                total_weight += weight
    
    print(f"{total_weight} {len(final_mst)}")
    for u, v in final_mst:
        print(f"{u} {v}")

if __name__ == "__main__":
    main()
