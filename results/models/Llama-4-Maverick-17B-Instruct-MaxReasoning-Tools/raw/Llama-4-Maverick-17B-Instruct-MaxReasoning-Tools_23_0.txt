# Lunar Lander Controller

This is a simple implementation of a lunar lander controller in Rust. The controller reads the initial map and continuous state updates from stdin, and outputs thrust and turn commands to stdout.

## Code

```rust
use std::io::{self, BufRead, BufReader, Write};
use std::thread;
use std::time::Duration;

struct LanderState {
    x: f64,
    y: f64,
    vx: f64,
    vy: f64,
    angle: f64,
    angular_vel: f64,
    fuel_remaining: f64,
}

struct Config {
    width: usize,
    height: usize,
    gravity: f64,
    max_thrust: f64,
    fuel: f64,
    target_x: f64,
    target_y: f64,
}

fn read_initial_map(reader: &mut BufReader<io::Stdin>) -> (Config, Vec<String>) {
    let mut line = String::new();
    reader.read_line(&mut line).unwrap();
    let mut parts = line.trim().split_whitespace();
    let width = parts.next().unwrap().parse().unwrap();
    let height = parts.next().unwrap().parse().unwrap();
    let gravity = parts.next().unwrap().parse().unwrap();
    let max_thrust = parts.next().unwrap().parse().unwrap();
    let fuel = parts.next().unwrap().parse().unwrap();

    line.clear();
    reader.read_line(&mut line).unwrap();
    parts = line.trim().split_whitespace();
    let start_x = parts.next().unwrap().parse().unwrap();
    let start_y = parts.next().unwrap().parse().unwrap();
    let target_x = parts.next().unwrap().parse().unwrap();
    let target_y = parts.next().unwrap().parse().unwrap();

    let mut map = Vec::new();
    for _ in 0..height {
        line.clear();
        reader.read_line(&mut line).unwrap();
        map.push(line.trim().to_string());
    }

    let config = Config {
        width,
        height,
        gravity,
        max_thrust,
        fuel,
        target_x,
        target_y,
    };

    (config, map)
}

fn read_state_update(reader: &mut BufReader<io::Stdin>) -> LanderState {
    let mut line = String::new();
    reader.read_line(&mut line).unwrap();
    let mut parts = line.trim().split_whitespace();
    LanderState {
        x: parts.next().unwrap().parse().unwrap(),
        y: parts.next().unwrap().parse().unwrap(),
        vx: parts.next().unwrap().parse().unwrap(),
        vy: parts.next().unwrap().parse().unwrap(),
        angle: parts.next().unwrap().parse().unwrap(),
        angular_vel: parts.next().unwrap().parse().unwrap(),
        fuel_remaining: parts.next().unwrap().parse().unwrap(),
    }
}

fn control_lander(state: &LanderState, config: &Config) -> (f64, f64) {
    // Simple control logic: try to land on target with low velocity
    let dx = config.target_x - state.x;
    let dy = config.target_y - state.y;
    let dist = (dx * dx + dy * dy).sqrt();
    let thrust = if dist > 10.0 { 0.5 } else { 0.1 }; // adjust thrust based on distance to target
    let turn = if dx > 0.0 { 0.1 } else { -0.1 }; // turn towards target

    // Adjust angle to face downwards when close to target
    if dist < 5.0 {
        if state.angle > 0.1 {
            turn = -0.5;
        } else if state.angle < -0.1 {
            turn = 0.5;
        }
    }

    // Limit thrust and turn to valid ranges
    let thrust = thrust.max(0.0).min(1.0);
    let turn = turn.max(-1.0).min(1.0);

    (thrust, turn)
}

fn main() {
    let mut reader = BufReader::new(io::stdin());
    let (config, _map) = read_initial_map(&mut reader);

    let mut stdout = io::stdout();
    let mut state = LanderState {
        x: 0.0,
        y: 0.0,
        vx: 0.0,
        vy: 0.0,
        angle: 0.0,
        angular_vel: 0.0,
        fuel_remaining: config.fuel,
    };

    loop {
        state = read_state_update(&mut reader);
        let (thrust, turn) = control_lander(&state, &config);
        writeln!(stdout, "{} {}", thrust, turn).unwrap();
        stdout.flush().unwrap();

        // Sleep for a short duration to avoid using 100% CPU
        thread::sleep(Duration::from_millis(20));
    }
}
```

## Explanation

This code reads the initial map and continuous state updates from stdin, and outputs thrust and turn commands to stdout. The control logic is simple: it tries to land on the target with low velocity by adjusting thrust and turn based on the distance to the target.

The code uses a `BufReader` to read from stdin and a `BufWriter` is not needed as we are using `io::stdout()` directly. The `control_lander` function implements the control logic, and the `main` function reads the initial map, reads state updates, and outputs control commands.

The code is designed to be efficient and avoid using 100% CPU. It sleeps for a short duration between state updates to avoid busy-waiting.

## Note

This is a basic implementation and may need to be adjusted based on the specific requirements of the lunar lander game. The control logic can be improved to handle different scenarios, such as obstacles or varying gravity. Additionally, the code can be optimized for performance and robustness.
