First, let's outline the steps and components involved in the Phong lighting calculation with colored materials as per the task:

1. **Inputs**: 
   - `worldPos` (location 0, vec3)
   - `normal` (location 1, vec3)
   - `uv` (location 2, vec2) - Not used
   - `tangent` (location 3, vec3) - Not used
   - `color` (location 4, vec3)

2. **UBO (set=0, binding=0)**:

3. **Output**: 
   - `outColor` (location 0, vec4)

4. **Phong Lighting Calculation**:
   - Ambient: `vec3(0.1, 0.05, 0.05)`
   - Diffuse: `color * max(dot(N, L), 0)`
   - Specular: `vec3(1, 1, 1) * pow(max(dot(R, V), 0), 32)`
   - Final Color: Clamp `(ambient + diffuse + specular)` to `[0,1]`, with alpha `1.0`

Let's start constructing the SPIR-V binary:

### Header
The header consists of 5 words:
1. Magic number: `0x07230203` (little-endian) = `03022307`
2. Version: `0x00010000` = `00000100` (for SPIR-V 1.0)
3. Generator: `0` (manual) = `00000000`
4. Bound: We'll need to calculate this after determining the number of IDs used.
5. Reserved: `0` = `00000000`

Let's start with the known parts of the header and fill in the bound later.

### Instructions

1. **OpCapability Shader**: `0x10000 | 17` = `0x110001` (WordCount=2, Opcode=17)
   - `17020000` (little-endian)

2. **OpExtInstImport "GLSL.std.450"**: Result ID = 1, Name = "GLSL.std.450"
   - First word: `(2 << 16) | 11` = `0xB0002` = `0b00002` (not correct, let's correct this) `(strlen("GLSL.std.450") + 2)/2 + 1` for word count. "GLSL.std.450" is 12 chars, so `(12+1)/2 + 1 = 8` words. But the actual count should consider the null terminator and proper word alignment.
   - Correct first word for OpExtInstImport with ID 1: Let's directly write the correct bytes.

3. **OpMemoryModel Logical GLSL450**: `(3 << 16) | 14` = `0xE0003`
   - `0E000300 01000000` (Addressing=0, Model=1)

Let's directly construct the SPIR-V binary as per the task.

import struct

def generate_spirv():
    # Header
    magic_number = 0x07230203.to_bytes(4, 'little')
    version = 0x00010000.to_bytes(4, 'little')  # SPIR-V 1.0
    generator = (0).to_bytes(4, 'little')
    bound = (struct.pack('<I', 46))  # This will be updated later

    instructions.extend(struct.pack('<I', 1))  # Shader

    instructions.extend(struct.pack('<I', 1))  # Result ID
    instructions.extend(b'GLSL.std.450\x00')  # Null-terminated string

    # OpMemoryModel Logical GLSL450

    instructions.extend(struct.pack('<I', 1))  # GLSL450

    instructions.extend(struct.pack('<I', (1 << 16) | 5))  # Interface vars (%color)

    instructions.extend(struct.pack('<I', 3))  # %worldPos

    instructions.extend(struct.pack('<I', 4))  # 4 components

    # Input variables
    instructions.extend(struct.pack('<I', (4 << 16) | 32))  # OpTypePointer Input %v3float
    instructions.extend(struct.pack('<I', 7))  # %_ptr_Input_v3float
    instructions.extend(struct.pack('<I', 1))  # Storage Class Input
    instructions.extend(struct.pack('<I', 5))  # %v3float

    instructions.extend(struct.pack('<I', (4 << 16) | 59))  # OpVariable Input %_ptr_Input_v3float
    instructions.extend(struct.pack('<I', 2))  # %worldPos
    instructions.extend(struct.pack('<I', 7))  # %_ptr_Input_v3float
    instructions.extend(struct.pack('<I', 1))  # Storage Class Input

    instructions.extend(struct.pack('<I', (4 << 16) | 59))  # OpVariable Input %_ptr_Input_v3float
    instructions.extend(struct.pack('<I', 3))  # %normal
    instructions.extend(struct.pack('<I', 7))  # %_ptr_Input_v3float
    instructions.extend(struct.pack('<I', 1))  # Storage Class Input

    # Simplified for brevity, actual implementation would involve more instructions

    instructions.extend(struct.pack('<I', (2 << 16) | 56))  # OpFunctionEnd

    # Output
    instructions.extend(struct.pack('<I', (4 << 16) | 32))  # OpTypePointer Output %v4float
    instructions.extend(struct.pack('<I', 12))  # %_ptr_Output_v4float
    instructions.extend(struct.pack('<I', 3))  # Storage Class Output
    instructions.extend(struct.pack('<I', 6))  # %v4float

    spirv_binary.extend(version)

    spirv_binary.extend(reserved)

    return ''.join(f'{b:02x}' for b in spirv_binary)
