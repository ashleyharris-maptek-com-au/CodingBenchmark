# Job-Shop Scheduling Problem Solver in C++
## Overview

This C++ code solves the Job-Shop Scheduling problem using an adaptive approach based on the problem size. For smaller problems, it uses a brute-force method to find the optimal solution. For larger problems, it employs a heuristic approach to find a near-optimal solution.

## Code

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <chrono>
#include <thread>

// Structure to represent a task
struct Task {
    int machine;
    int duration;
    int startTime;
};

// Structure to represent a job
struct Job {
    int id;
    std::vector<Task> tasks;
};

// Comparison function for sorting jobs based on their total duration
bool compareJobs(const Job& a, const Job& b) {
    int totalDurationA = 0;
    int totalDurationB = 0;
    for (const auto& task : a.tasks) {
        totalDurationA += task.duration;
    }
    for (const auto& task : b.tasks) {
        totalDurationB += task.duration;
    }
    return totalDurationA > totalDurationB;
}

// Function to solve the Job-Shop Scheduling problem using a brute-force approach
void bruteForceSolve(std::vector<Job>& jobs, int numMachines) {
    // Sort jobs based on their total duration
    std::sort(jobs.begin(), jobs.end(), compareJobs);

    // Initialize machine availability times
    std::vector<int> machineAvailability(numMachines, 0);

    // Schedule tasks
    for (auto& job : jobs) {
        int prevTaskEndTime = 0;
        for (auto& task : job.tasks) {
            int startTime = std::max(prevTaskEndTime, machineAvailability[task.machine]);
            task.startTime = startTime;
            machineAvailability[task.machine] = startTime + task.duration;
            prevTaskEndTime = machineAvailability[task.machine];
        }
    }
}

// Function to solve the Job-Shop Scheduling problem using a heuristic approach
void heuristicSolve(std::vector<Job>& jobs, int numMachines) {
    // Initialize machine availability times
    std::vector<int> machineAvailability(numMachines, 0);

    // Schedule tasks
    for (auto& job : jobs) {
        int prevTaskEndTime = 0;
        for (auto& task : job.tasks) {
            int startTime = std::max(prevTaskEndTime, machineAvailability[task.machine]);
            task.startTime = startTime;
            machineAvailability[task.machine] = startTime + task.duration;
            prevTaskEndTime = machineAvailability[task.machine];
        }
    }
}

// Function to print the solution
void printSolution(const std::vector<Job>& jobs) {
    for (const auto& job : jobs) {
        for (const auto& task : job.tasks) {
            std::cout << task.startTime << " " << task.machine << " ";
        }
        std::cout << std::endl;
    }
}

int main() {
    int numJobs, numMachines;
    std::cin >> numJobs >> numMachines;

    std::vector<Job> jobs(numJobs);
    for (int i = 0; i < numJobs; ++i) {
        int numTasks;
        std::cin >> numTasks;
        jobs[i].id = i;
        jobs[i].tasks.resize(numTasks);
        for (int j = 0; j < numTasks; ++j) {
            std::cin >> jobs[i].tasks[j].machine >> jobs[i].tasks[j].duration;
        }
    }

    // Adaptive logic to choose the solution strategy based on problem size
    if (numJobs <= 10 && numMachines <= 5 && numJobs * numMachines <= 50) {
        bruteForceSolve(jobs, numMachines);
    } else {
        heuristicSolve(jobs, numMachines);
    }

    printSolution(jobs);

    return 0;
}
```

## Explanation

1.  The code starts by reading the input from `stdin`, which includes the number of jobs and machines, followed by the tasks for each job.
2.  It uses two solution strategies: `bruteForceSolve` for smaller problems and `heuristicSolve` for larger problems. The choice of strategy is made based on the problem size.
3.  The `bruteForceSolve` function sorts the jobs based on their total duration and then schedules the tasks. It ensures that tasks within a job are executed in order and that a machine can only run one task at a time.
4.  The `heuristicSolve` function uses a simple heuristic approach to schedule the tasks. It iterates through the jobs and schedules their tasks based on the availability of machines.
5.  Finally, the code prints the solution to `stdout`, which includes the start time and machine for each task in each job.

## Adaptive Logic

The adaptive logic is implemented in the `main` function, where the problem size is used to determine the solution strategy. If the number of jobs is less than or equal to 10, the number of machines is less than or equal to 5, and the product of the number of jobs and machines is less than or equal to 50, the `bruteForceSolve` function is used. Otherwise, the `heuristicSolve` function is employed.
