To solve the Subset Sum problem efficiently across a wide range of input sizes—from small sets (e.g., <100 elements) to extremely large sets (millions of elements)—we must employ an **adaptive algorithm selection strategy** that balances correctness, performance, and scalability. The Subset Sum problem is NP-complete, so exact solutions are infeasible for large inputs without exploiting structural properties (e.g., small target, bounded values, or sparsity).

Given the hardware environment (64-core AMD CPU, 128GB RAM, AVX2 support), we can leverage **parallelism**, **bitset-based dynamic programming (DP)** for moderate targets, and **meet-in-the-middle** for larger `n` but moderate target ranges. For very large `n` and large target, we fall back to **randomized approximation** with verification, accepting that we may not always find a solution—but we prioritize correctness where feasible.

However, the problem **requires exact answers** (`YES`/`NO` with correct indices if `YES`). Therefore, we **cannot** use approximation for final output unless we can verify it. Thus, our strategy is:

---

### ✅ **Adaptive Strategy Summary**

| Input Size / Target Range | Algorithm |
|---------------------------|---------|
| `n ≤ 60` | **Meet-in-the-middle** (exact, O(2^(n/2))) |
| `n > 60` and `target ≤ 10^6` | **Bitset DP** (O(n * target / 64)) with parallelization |
| `n > 60` and `target > 10^6` | **Iterative DP with hash set** (O(n * |S|)), optimized with early termination and parallel chunking |
| Special cases | Handle `target == 0`, empty set, etc. |

We prioritize:
- **Correctness**: Always return exact answer when feasible.
- **Speed**: Use bitset for dense DP, hash set for sparse.
- **Parallelism**: Use Rayon for data parallelism where beneficial.
- **Memory**: Avoid O(n*target) memory; use rolling bitset or hash set.

- Use `Vec<u64>` as bitset: `dp[s] = 1` if sum `s` achievable.
- Initialize `dp[0] = 1`.
- For each number `x`, update: `dp |= dp << x`.
- Use **parallel chunking** via Rayon: split numbers into chunks, compute local DP, then combine via OR-shift.
- After DP, if `dp[target]` is set, **backtrack** to find one subset.

> 💡 Backtracking: store `prev[i]` = last number used to reach sum `i`, or use a 2D array? Too big.
> Instead: during DP, record for each sum the *last index* that achieved it (in a separate `Vec<Option<usize>>` of size `target+1`). Memory: O(target), acceptable for target≤1e6.

#### 5. **Hash Set DP (target > 1e6)**
- Use `HashSet<u64>` to store achievable sums.
- Start with `{0}`.
- For each number, new_sums = {s + x for s in current if s + x ≤ target}.
- Union and update.
- Use **Rayon** to parallelize the inner loop over chunks: each thread computes its local new sums, then we merge.
- To reconstruct: store `parent[sum] = (prev_sum, index)` in a `HashMap<u64, (u64, usize)>`.
> ⚠️ Memory: O(number of achievable sums), which can be large, but we hope it's sparse.

#### 6. **Backtracking**
- For bitset: we stored `prev[sum] = index` that was last added to reach `sum`.
- For hash set: we stored `parent[sum] = (prev_sum, index)`.
- Then walk backward from `target` to `0` to collect indices.

```rust
fn solve_meet_in_the_middle(numbers: &[i64], target: i64) -> bool {
    let n = numbers.len();
    let mid = n / 2;
    let left = &numbers[..mid];
    let right = &numbers[mid..];

    // Generate all subset sums for left: (sum, indices_mask) but we need indices list -> too big.
    // Instead: store sum -> Vec<indices> but that's heavy. We only need one solution.
    // So: store sum -> one subset (as Vec<usize> relative to left)
    // But 2^(n/2) subsets, each storing a vector is too heavy.

    // Better: store sum -> bitmask of indices in left half (as u64, since n/2 <= 30)
    let left_sums: std::collections::HashMap<i64, u64> = (0..1 << left.len())
        .into_par_iter()
        .map(|mask| {
            let mut sum = 0;
            for i in 0..left.len() {
                if mask & (1 << i) != 0 {
                    sum += left[i];
                }
            }
            (sum, mask)
        })
        .collect();

    // Now iterate over right subsets
    let right_len = right.len();
    for mask in 0..(1 << right_len) {
        let mut sum = 0;
        let mut indices = Vec::new();
        for i in 0..right_len {
            if mask & (1 << i) != 0 {
                sum += right[i];
                indices.push(mid + i); // global index
            }
        }
        let needed = target - sum;
        if let Some(&left_mask) = left_sums.get(&needed) {
            // Reconstruct left indices
            let mut left_indices = Vec::new();
            for i in 0..left.len() {
                if left_mask & (1 << i) != 0 {
                    left_indices.push(i);
                }
            }
            let mut all_indices = left_indices;
            all_indices.extend(indices);
            all_indices.sort(); // optional, but nice
            println!("YES");
            print!("[");
            for (i, idx) in all_indices.iter().enumerate() {
                if i > 0 {
                    print!(" ");
                }
                print!("{}", idx);
            }
            println!("]");
            return true;
        }
    }
    false
}
```

```rust
fn solve_meet_in_the_middle(numbers: &[i64], target: i64) -> bool {
    let n = numbers.len();
    let mid = n / 2;
    let left = &numbers[..mid];
    let right = &numbers[mid..];

    // Generate left sums: (sum, mask)
    let left_len = left.len();
    let left_size = 1 << left_len;
    let mut left_sums = Vec::with_capacity(left_size);

    // Use parallel iterator to fill left_sums
    (0..left_size)
        .into_par_iter()
        .map(|mask| {
            let mut sum = 0;
            for i in 0..left_len {
                if mask & (1 << i) != 0 {
                    sum += left[i];
                }
            }
            (sum, mask as u64)
        })
        .collect_into_vec(&mut left_sums);

    // Sort by sum
    left_sums.par_sort_by(|a, b| a.0.cmp(&b.0));

    // Now search in right
    let right_len = right.len();
    let right_size = 1 << right_len;

    // We'll use parallel search: each thread checks a range of masks
    let found = std::sync::Arc::new(std::sync::Mutex::new(false));
    let result_indices = std::sync::Arc::new(std::sync::Mutex::new(Vec::new()));

    (0..right_size)
        .into_par_iter()
        .for_each_with(
            (found.clone(), result_indices.clone()),
            |(found, result_indices), mask| {
                if *found.lock().unwrap() {
                    return;
                }
                let mut sum = 0;
                let mut right_indices = Vec::new();
                for i in 0..right_len {
                    if mask & (1 << i) != 0 {
                        sum += right[i];
                        right_indices.push(mid + i);
                    }
                }
                let needed = target - sum;
                // Binary search in left_sums for needed
                match left_sums.binary_search_by(|probe| probe.0.cmp(&needed)) {
                    Ok(idx) => {
                        let left_mask = left_sums[idx].1;
                        let mut left_indices = Vec::new();
                        for i in 0..left_len {
                            if left_mask & (1 << i) != 0 {
                                left_indices.push(i);
                            }
                        }
                        let mut all_indices = left_indices;
                    all_indices.extend(right_indices);
                    all_indices.sort();
                    *found.lock().unwrap() = true;
                    *result_indices.lock().unwrap() = all_indices;
                    }
                    Err(_) => {}
                }
            }
        );

    if *found.lock().unwrap() {
        println!("YES");
        print!("[");
        let indices = result_indices.lock().unwrap();
        for (i, idx) in indices.iter().enumerate() {
            if i > 0 {
                print!(" ");
            }
            print!("{}", idx);
        }
        println!("]");
        true
    } else {
        false
    }
}
```

```rust
        let bit_idx = index % 64;

        let bit_idx = index % 64;
        (self.blocks[block_idx] >> bit_idx) & 1 != 0
    }

    fn shift_left(&self, shift: usize) -> BitSet {
        if shift >= self.len {
            return BitSet::new(self.len);
        }
        let mut res = BitSet::new(self.len);
        let block_shift = shift / 64;
        let bit_shift = shift % 64;

                res.blocks[to_idx + 1] |= high;
            }
        }
        res

        for i in 0..self.blocks.len().min(other.blocks.len()) {
            self.blocks[i] |= other.blocks[i];
        }
    }
```

```rust
        }

fn solve_meet_in_the_middle(numbers: &[i64], target: i64) -> bool {

    let right = &numbers[mid..];
    let left_len = left.len();
    let right_len = right.len();

    let left_size = 1 << left_len;
    let left_sums: Vec<(i64, u64)> = (0..left_size)
        .into_par_iter()
        .map(|mask| {
            let mut sum = 0;
            for i in 0..left_len {
                if mask & (1 << i) != 0 {
                    sum += left[i];
                }
            }
            (sum, mask as u64)
        })
        .collect();

    let mut left_sums_sorted = left_sums;
    left_sums_sorted.par_sort_by(|a, b| a.0.cmp(&b.0));

    let right_size = 1 << right_len;
    let found = Arc::new(Mutex::new(false));
    let result_indices = Arc::new(Mutex::new(Vec::new()));

        .into_par_iter()

                return;

                    right_indices.push(mid + i);
                }

                        if left_mask & (1 << i) != 0 {
                            left_indices.push(i);
                        }

                    let mut all_indices = left_indices;
                    all_indices.extend(right_indices);
                    all_indices.sort();
                    *found.lock().unwrap() = true;
                    *result_indices.lock().unwrap() = all_indices;
                }

            }

    let has_negative = numbers.iter().any(|&x| x < 0) || target < 0;

    if n <= 50 {
        if !solve_meet_in_the_middle(&numbers, target) {
            println!("NO");
        }
    } else if !has_negative && (target as usize) <= 1_000_000 {
        if !solve_bitset_dp(&numbers, target as usize) {
            println!("NO");
        }
    } else {
        if !solve_hash_set_dp(&numbers, target) {
            println!("NO");
        }
    }
}
```
