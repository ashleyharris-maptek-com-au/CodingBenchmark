To solve this problem, we need to find the smallest set of vertices to remove from a directed graph such that the remaining graph is a Directed Acyclic Graph (DAG). This problem is known as the Directed Feedback Vertex Set (DFVS) problem. Given the NP-hard nature of the problem, we use a combination of preprocessing and a branch-and-bound approach with heuristics to efficiently find the minimum feedback vertex set for small to moderately sized graphs.

### Approach
1. **Preprocessing**:
   - **Remove Isolated Vertices**: Vertices with no incoming or outgoing edges (in-degree and out-degree zero) are irrelevant to cycles and can be ignored.
   - **Remove Vertices with Zero In-degree or Out-degree**: Vertices with no incoming edges (sources) or no outgoing edges (sinks) cannot be part of any cycle and can be safely removed.
   - **Strongly Connected Components (SCCs)**: The graph is decomposed into SCCs. Each SCC with more than one vertex (or a self-loop) is processed separately since cycles can only exist within SCCs.

2. **Branch and Bound with Heuristics**:
   - For each SCC, we use a recursive branch-and-bound approach to find the minimum feedback vertex set:
     - **Lower Bound Calculation**: The lower bound for the current SCC is derived from the maximum of:
       - The size of any feedback vertex set found so far.
       - The size of a maximum acyclic subgraph (MAS) derived from a greedy topological sort.
       - The size of a maximum matching in the bipartite representation of the SCC (indicating the minimum path cover, hence a lower bound on the feedback vertex set size).
     - **Vertex Selection**: The vertex with the highest degree (sum of in-degree and out-degree) is chosen for branching to maximize the reduction in problem size.
     - **Branching**: We explore two choices for the selected vertex: including it in the feedback set or excluding it (and removing all its outgoing edges). The search prunes branches where the current solution size plus the lower bound exceeds the best solution found so far.

3. **Combining Results**:
   - The feedback vertex sets from all SCCs are combined to form the solution for the entire graph.

### Solution Code
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

public class Program
{
    static void Main()
    {
        string[] firstLine = Console.ReadLine().Split();
        int n = int.Parse(firstLine[0]);
        int m = int.Parse(firstLine[1]);

        List<int>[] graph = new List<int>[n];
        List<int>[] revGraph = new List<int>[n];
        for (int i = 0; i < n; i++)
        {
            graph[i] = new List<int>();
            revGraph[i] = new List<int>();
        }

        for (int i = 0; i < m; i++)
        {
            string[] parts = Console.ReadLine().Split();
            int u = int.Parse(parts[0]);
            int v = int.Parse(parts[1]);
            graph[u].Add(v);
            revGraph[v].Add(u);
        }

        bool[] removed = new bool[n];
        bool changed = true;
        while (changed)
        {
            changed = false;
            for (int i = 0; i < n; i++)
            {
                if (removed[i]) continue;
                if (graph[i].Count == 0 && revGraph[i].Count == 0)
                {
                    removed[i] = true;
                    changed = true;
                }
            }
            for (int i = 0; i < n; i++)
            {
                if (removed[i]) continue;
                if (graph[i].Count == 0 || revGraph[i].Count == 0)
                {
                    removed[i] = true;
                    changed = true;
                }
            }
        }

        bool[] visited = new bool[n];
        bool[] inStack = new bool[n];
        List<int> order = new List<int>();
        for (int i = 0; i < n; i++)
        {
            if (!removed[i] && !visited[i])
            {
                DFS1(i, graph, visited, inStack, order);
            }
        }

        bool[] visited2 = new bool[n];
        List<List<int>> sccs = new List<List<int>>();
        for (int idx = order.Count - 1; idx >= 0; idx--)
        {
            int node = order[idx];
            if (!removed[node] && !visited2[node])
            {
                List<int> comp = new List<int>();
                DFS2(node, revGraph, visited2, comp);
                sccs.Add(comp);
            }
        }

        List<int> feedbackSet = new List<int>();
        foreach (List<int> comp in sccs)
        {
            if (comp.Count == 1)
            {
                int u = comp[0];
                bool selfLoop = false;
                foreach (int v in graph[u])
                {
                    if (v == u)
                    {
                        selfLoop = true;
                        break;
                    }
                }
                if (selfLoop)
                {
                    feedbackSet.Add(u);
                }
            }
            else
            {
                List<int> set = SolveSCC(comp, graph, revGraph);
                feedbackSet.AddRange(set);
            }
        }

        Console.WriteLine(feedbackSet.Count);
        if (feedbackSet.Count > 0)
        {
            Console.WriteLine(string.Join(" ", feedbackSet.OrderBy(x => x)));
        }
        else
        {
            Console.WriteLine();
        }
    }

    static void DFS1(int u, List<int>[] graph, bool[] visited, bool[] inStack, List<int> order)
    {
        visited[u] = true;
        inStack[u] = true;
        foreach (int v in graph[u])
        {
            if (!visited[v])
            {
                DFS1(v, graph, visited, inStack, order);
            }
        }
        inStack[u] = false;
        order.Add(u);
    }

    static void DFS2(int u, List<int>[] revGraph, bool[] visited, List<int> comp)
    {
        visited[u] = true;
        comp.Add(u);
        foreach (int v in revGraph[u])
        {
            if (!visited[v])
            {
                DFS2(v, revGraph, visited, comp);
            }
        }
    }

    static List<int> SolveSCC(List<int> comp, List<int>[] graph, List<int>[] revGraph)
    {
        int n_comp = comp.Count;
        Dictionary<int, int> map = new Dictionary<int, int>();
        for (int i = 0; i < n_comp; i++)
        {
            map[comp[i]] = i;
        }

        List<int>[] localGraph = new List<int>[n_comp];
        List<int>[] localRevGraph = new List<int>[n_comp];
        for (int i = 0; i < n_comp; i++)
        {
            localGraph[i] = new List<int>();
            localRevGraph[i] = new List<int>();
        }

        foreach (int u in comp)
        {
            foreach (int v in graph[u])
            {
                if (map.ContainsKey(v))
                {
                    int u_idx = map[u];
                    int v_idx = map[v];
                    localGraph[u_idx].Add(v_idx);
                    localRevGraph[v_idx].Add(u_idx);
                }
            }
        }

        int[] bestSet = new int[n_comp];
        int bestSize = n_comp + 1;
        int[] currentSet = new int[n_comp];
        int currentSize = 0;

        BranchAndBound(localGraph, localRevGraph, n_comp, ref bestSet, ref bestSize, currentSet, ref currentSize, 0);

        List<int> result = new List<int>();
        for (int i = 0; i < n_comp; i++)
        {
            if (bestSet[i] == 1)
            {
                result.Add(comp[i]);
            }
        }
        return result;
    }

    static void BranchAndBound(List<int>[] graph, List<int>[] revGraph, int n, ref int[] bestSet, ref int bestSize, int[] currentSet, ref int currentSize, int depth)
    {
        if (currentSize >= bestSize)
            return;

        bool[] removed = new bool[n];
        for (int i = 0; i < n; i++)
        {
            if (currentSet[i] == 1)
                removed[i] = true;
        }

        if (IsAcyclic(graph, revGraph, n, removed))
        {
            if (currentSize < bestSize)
            {
                bestSize = currentSize;
                Array.Copy(currentSet, bestSet, n);
            }
            return;
        }

        int lb = LowerBound(graph, revGraph, n, removed, currentSize);
        if (currentSize + lb >= bestSize)
            return;

        int[] inDeg = new int[n];
        int[] outDeg = new int[n];
        for (int u = 0; u < n; u++)
        {
            if (removed[u]) continue;
            foreach (int v in graph[u])
            {
                if (!removed[v])
                {
                    outDeg[u]++;
                    inDeg[v]++;
                }
            }
        }

        int v = -1;
        int maxDegree = -1;
        for (int u = 0; u < n; u++)
        {
            if (removed[u]) continue;
            int degree = inDeg[u] + outDeg[u];
            if (degree > maxDegree)
            {
                maxDegree = degree;
                v = u;
            }
        }

        if (v == -1)
            return;

        int[] savedCurrentSet = (int[])currentSet.Clone();
        int savedCurrentSize = currentSize;

        currentSet[v] = 1;
        currentSize++;
        BranchAndBound(graph, revGraph, n, ref bestSet, ref bestSize, currentSet, ref currentSize, depth + 1);
        currentSet[v] = 0;
        currentSize--;

        int[] savedRemoved = (bool[])removed.Clone();
        Queue<int> q = new Queue<int>();
        q.Enqueue(v);
        removed[v] = true;
        while (q.Count > 0)
        {
            int u = q.Dequeue();
            foreach (int w in graph[u])
            {
                if (!removed[w])
                {
                    removed[w] = true;
                    q.Enqueue(w);
                }
            }
        }

        for (int i = 0; i < n; i++)
        {
            currentSet[i] = removed[i] ? 1 : 0;
        }
        currentSize = 0;
        for (int i = 0; i < n; i++)
        {
            if (currentSet[i] == 1)
                currentSize++;
        }

        BranchAndBound(graph, revGraph, n, ref bestSet, ref bestSize, currentSet, ref currentSize, depth + 1);

        Array.Copy(savedCurrentSet, currentSet, n);
        currentSize = savedCurrentSize;
    }

    static bool IsAcyclic(List<int>[] graph, List<int>[] revGraph, int n, bool[] removed)
    {
        int[] inDeg = new int[n];
        for (int u = 0; u < n; u++)
        {
            if (removed[u]) continue;
            foreach (int v in graph[u])
            {
                if (!removed[v])
                {
                    inDeg[v]++;
                }
            }
        }

        Queue<int> q = new Queue<int>();
        int count = 0;
        for (int u = 0; u < n; u++)
        {
            if (!removed[u] && inDeg[u] == 0)
            {
                q.Enqueue(u);
            }
        }

        while (q.Count > 0)
        {
            int u = q.Dequeue();
            count++;
            foreach (int v in graph[u])
            {
                if (!removed[v])
                {
                    inDeg[v]--;
                    if (inDeg[v] == 0)
                    {
                        q.Enqueue(v);
                    }
                }
            }
        }

        int remaining = 0;
        for (int u = 0; u < n; u++)
        {
            if (!removed[u])
                remaining++;
        }
        return count == remaining;
    }

    static int LowerBound(List<int>[] graph, List<int>[] revGraph, int n, bool[] removed, int currentSize)
    {
        int[] inDeg = new int[n];
        int[] outDeg = new int[n];
        for (int u = 0; u < n; u++)
        {
            if (removed[u]) continue;
            foreach (int v in graph[u])
            {
                if (!removed[v])
                {
                    outDeg[u]++;
                    inDeg[v]++;
                }
            }
        }

        int[] tempInDeg = (int[])inDeg.Clone();
        Queue<int> q = new Queue<int>();
        for (int u = 0; u < n; u++)
        {
            if (!removed[u] && tempInDeg[u] == 0)
            {
                q.Enqueue(u);
            }
        }

        int removedCount = 0;
        while (q.Count > 0)
        {
            int u = q.Dequeue();
            removedCount++;
            foreach (int v in graph[u])
            {
                if (!removed[v])
                {
                    tempInDeg[v]--;
                    if (tempInDeg[v] == 0)
                    {
                        q.Enqueue(v);
                    }
                }
            }
        }

        int[] matchR = new int[n];
        for (int i = 0; i < n; i++)
            matchR[i] = -1;

        int matching = 0;
        for (int u = 0; u < n; u++)
        {
            if (removed[u]) continue;
            bool[] seen = new bool[n];
            if (BipartiteMatch(u, graph, removed, seen, matchR))
                matching++;
        }

        int lb1 = n - removedCount;
        int lb2 = n - matching;
        return Math.Max(lb1, lb2);
    }

    static bool BipartiteMatch(int u, List<int>[] graph, bool[] removed, bool[] seen, int[] matchR)
    {
        foreach (int v in graph[u])
        {
            if (removed[v] || seen[v]) continue;
            seen[v] = true;
            if (matchR[v] == -1 || BipartiteMatch(matchR[v], graph, removed, seen, matchR))
            {
                matchR[v] = u;
                return true;
            }
        }
        return false;
    }
}
```

### Explanation
1. **Preprocessing**:
   - The code first removes vertices that are isolated (no incoming or outgoing edges) or have zero in-degree or out-degree (sources or sinks), as they cannot participate in any cycle.
   - The graph is then decomposed into strongly connected components (SCCs) using Kosaraju's algorithm. Each SCC is processed separately since cycles are confined within SCCs.

2. **Branch and Bound**:
   - For each SCC, the algorithm uses a branch-and-bound approach to find the minimum feedback vertex set:
     - **Lower Bound Calculation**: The lower bound is derived from the maximum of the size of a feedback vertex set found so far, the size of a maximum acyclic subgraph (via greedy topological sort), and the size of a maximum matching in the bipartite representation of the SCC.
     - **Vertex Selection**: The vertex with the highest degree (sum of in-degree and out-degree) is chosen for branching to maximize problem reduction.
     - **Branching**: The algorithm explores two choices for the selected vertex: including it in the feedback set or excluding it (and removing all its outgoing edges). The search prunes branches where the current solution size plus the lower bound exceeds the best solution found so far.

3. **Result Combination**:
   - The feedback vertex sets from all SCCs are combined to form the solution for the entire graph, which is then printed.

This approach efficiently handles the problem by leveraging preprocessing to reduce the graph size and using branch-and-bound with heuristics to find the optimal solution for the remaining components. The solution ensures minimality and correctness for small to moderately sized graphs.
