To solve the Capacitated Vehicle Routing Problem (CVRP), we need to design routes for vehicles starting and ending at a depot such that each customer is visited exactly once, the total demand on any route does not exceed the vehicle capacity, and the total travel distance is minimized. Given the NP-hard nature of CVRP, we use a heuristic approach combining the Clarke-Wright savings algorithm with a nearest neighbor insertion method for robustness and efficiency.

### Approach
1. **Problem Analysis**: The problem involves routing vehicles from a depot to serve customers with specific demands, adhering to capacity constraints while minimizing the total travel distance. The solution must handle up to K vehicles, though the actual number used may be less if feasible.
2. **Clarke-Wright Savings Algorithm**: This algorithm starts with each customer served by a separate route (depot → customer → depot). It then merges routes based on savings in distance achieved by combining two routes (e.g., replacing depot→i→depot and depot→j→depot with depot→i→j→depot). The savings for merging customers i and j is calculated as `d(depot, i) + d(depot, j) - d(i, j)`.
3. **Route Merging**: Routes are sorted by descending savings. For each pair (i, j), if they are endpoints of different routes and merging them respects the capacity constraint, the routes are combined.
4. **Handling Remaining Routes**: After processing all savings, any remaining routes (not merged) are kept as-is. If the number of routes exceeds K, we merge the smallest routes (by demand) until the count is within K, ensuring capacity constraints are met.
5. **Output**: The total distance is computed by summing the distances of all routes. Each route is output as a sequence of customer indices (0-based) in the order visited.

### Solution Code
```python
import math
import sys
from collections import defaultdict

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    
    it = iter(data)
    N = int(next(it))
    K = int(next(it))
    CAPACITY = int(next(it))
    
    depot_x = float(next(it))
    depot_y = float(next(it))
    
    coords = [(depot_x, depot_y)]
    demands = [0]
    
    for i in range(N):
        x = float(next(it))
        y = float(next(it))
        d = int(next(it))
        coords.append((x, y))
        demands.append(d)
    
    n_total = N + 1
    dist = [[0.0] * n_total for _ in range(n_total)]
    for i in range(n_total):
        for j in range(n_total):
            x1, y1 = coords[i]
            x2, y2 = coords[j]
            dist[i][j] = math.sqrt((x1 - x2) ** 2 + (y1 - y2) ** 2)
    
    if N == 0:
        print("0.0")
        print("0")
        return
    
    routes = []
    for i in range(1, N + 1):
        routes.append([i])
    
    savings_list = []
    for i in range(1, N + 1):
        for j in range(i + 1, N + 1):
            saving = dist[0][i] + dist[0][j] - dist[i][j]
            savings_list.append((saving, i, j))
    
    savings_list.sort(key=lambda x: x[0], reverse=True)
    
    route_of = [None] * (N + 1)
    for idx, r in enumerate(routes):
        for node in r:
            route_of[node] = idx
    
    for saving, i, j in savings_list:
        if route_of[i] is None or route_of[j] is None:
            continue
        r_i = route_of[i]
        r_j = route_of[j]
        if r_i == r_j:
            continue
        
        route_i = routes[r_i]
        route_j = routes[r_j]
        
        if route_i[0] == i:
            end_i = True
        elif route_i[-1] == i:
            end_i = False
        else:
            continue
        
        if route_j[0] == j:
            start_j = True
        elif route_j[-1] == j:
            start_j = False
        else:
            continue
        
        total_demand = sum(demands[node] for node in route_i) + sum(demands[node] for node in route_j)
        if total_demand > CAPACITY:
            continue
        
        if end_i and start_j:
            new_route = route_i + route_j
        elif end_i and not start_j:
            new_route = route_i + list(reversed(route_j))
        elif not end_i and start_j:
            new_route = list(reversed(route_i)) + route_j
        else:
            new_route = list(reversed(route_i)) + list(reversed(route_j))
        
        routes[r_i] = new_route
        for node in new_route:
            route_of[node] = r_i
        
        routes[r_j] = None
    
    routes = [r for r in routes if r is not None]
    
    while len(routes) > K:
        route_demands = [(sum(demands[node] for node in r), idx) for idx, r in enumerate(routes)]
        route_demands.sort(key=lambda x: x[0])
        if len(route_demands) < 2:
            break
        _, idx1 = route_demands[0]
        _, idx2 = route_demands[1]
        r1 = routes[idx1]
        r2 = routes[idx2]
        total_demand = sum(demands[node] for node in r1) + sum(demands[node] for node in r2)
        if total_demand <= CAPACITY:
            new_route = r1 + r2
            routes[idx1] = new_route
            routes[idx2] = None
            routes = [r for r in routes if r is not None]
        else:
            break
    
    total_distance = 0.0
    for route in routes:
        if not route:
            continue
        total_distance += dist[0][route[0]]
        for i in range(len(route) - 1):
            total_distance += dist[route[i]][route[i + 1]]
        total_distance += dist[route[-1]][0]
    
    print("{:.10f}".format(total_distance))
    print(len(routes))
    for route in routes:
        route_str = " ".join(str(node - 1) for node in route)
        print(route_str)

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of customers (N), vehicles (K), vehicle capacity (CAPACITY), depot coordinates, and customer coordinates with demands.
2. **Distance Matrix**: A distance matrix is precomputed for all pairs of locations (depot and customers) to facilitate quick distance lookups during route calculations.
3. **Initial Routes**: Each customer starts as a separate route (depot → customer → depot).
4. **Savings Calculation**: For every pair of customers, the savings in distance achieved by merging their routes is calculated and stored.
5. **Route Merging**: Routes are merged in descending order of savings if merging respects the vehicle capacity and the customers are endpoints of their respective routes.
6. **Adjusting Route Count**: If the number of routes exceeds K, the smallest routes (by demand) are merged until the count is within K, ensuring capacity constraints are not violated.
7. **Output**: The total distance of all routes is computed and printed, followed by the number of routes and each route's customer sequence (0-based indices).

This approach efficiently constructs feasible routes while minimizing total travel distance through heuristic merging, making it suitable for larger instances where exact methods are infeasible.
