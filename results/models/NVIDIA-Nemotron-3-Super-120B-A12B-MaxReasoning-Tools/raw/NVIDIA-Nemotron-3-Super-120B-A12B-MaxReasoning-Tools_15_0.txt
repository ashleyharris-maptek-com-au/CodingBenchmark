To solve the Shadow Covering problem with tetrahedrons, we need to ensure that the combined shadows of non-intersecting tetrahedrons completely cover a given polygon on the z=0 plane, while minimizing the number of tetrahedrons used. Each tetrahedron must be axis-aligned and scaled uniformly, with a maximum scale factor of 10.0.

### Approach
1. **Problem Analysis**:
   - The input is a simple polygon on the z=0 plane defined by NV vertices.
   - The sun direction vector (sx, sy, sz) indicates the direction from the sun to the ground (sz < 0).
   - Each tetrahedron is defined by a center position (px, py, pz), a rotation quaternion (qw, qx, qy, qz), and a uniform scale factor.
   - The shadow of a tetrahedron on the z=0 plane is the projection of the tetrahedron along the sun direction vector.

2. **Key Insights**:
   - For sz = -1 (sun directly overhead), the shadow of a tetrahedron is the projection of its base (in the xy-plane) after rotation. The base of the reference tetrahedron is a unit square in the xy-plane (vertices at (±1, 0) and (0, ±1)).
   - After rotation by quaternion (qw, qx, qy, qz) and scaling by factor s, the shadow becomes a square rotated by the quaternion's rotation and scaled by s, centered at (px, py).
   - To cover the polygon without overlapping tetrahedrons, we can use an axis-aligned grid of squares (shadows) where each square has a side length of 2.0 (scale factor 1.0). This ensures non-overlapping shadows (adjacent squares share edges but do not overlap in area).
   - The number of tetrahedrons needed is the number of grid squares that intersect the polygon.

3. **Algorithm Selection**:
   - **Bounding Box Calculation**: Compute the axis-aligned bounding box (AABB) of the polygon to determine the grid range.
   - **Grid Processing**: Iterate over each unit square in the grid that overlaps the AABB. For each square, check if it intersects the polygon using the ray casting algorithm (even-odd rule).
   - **Output Generation**: For each intersecting square, output a tetrahedron with:
     - Center at (i + 0.5, j + 0.5, 0.0) (center of the square in xy-plane, z=0).
     - Identity quaternion (1.0, 0.0, 0.0, 0.0) (no rotation).
     - Scale factor 1.0 (uniform scale, within the max limit of 10.0).

4. **Complexity Analysis**:
   - **Time Complexity**: O((width * height) * NV), where width and height are the dimensions of the AABB, and NV is the number of polygon vertices. For large polygons, this can be inefficient, but it is straightforward and correct for the problem constraints.
   - **Space Complexity**: O(NV) for storing the polygon vertices.

### Solution Code

```rust
use std::io::{self, Read};

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    let mut lines = input.lines();
    
    let nv: usize = lines.next().unwrap().trim().parse().unwrap();
    let mut polygon = Vec::new();
    for _ in 0..nv {
        let line = lines.next().unwrap();
        let mut parts = line.split_whitespace();
        let x: f64 = parts.next().unwrap().parse().unwrap();
        let y: f64 = parts.next().unwrap().parse().unwrap();
        polygon.push((x, y));
    }
    let sun_line = lines.next().unwrap();
    let mut sun_parts = sun_line.split_whitespace();
    let _sx: f64 = sun_parts.next().unwrap().parse().unwrap();
    let _sy: f64 = sun_parts.next().unwrap().parse().unwrap();
    let sz: f64 = sun_parts.next().unwrap().parse().unwrap();
    
    if polygon.is_empty() {
        println!("0");
        return;
    }
    
    let mut min_x = polygon[0].0;
    let mut max_x = polygon[0].0;
    let mut min_y = polygon[0].1;
    let mut max_y = polygon[0].1;
    for &(x, y) in &polygon {
        if x < min_x { min_x = x; }
        if x > max_x { max_x = x; }
        if y < min_y { min_y = y; }
        if y > max_y { max_y = y; }
    }
    
    let start_i = (min_x - 1.0).floor() as i32;
    let end_i = max_x.ceil() as i32;
    let start_j = (min_y - 1.0).floor() as i32;
    let end_j = max_y.ceil() as i32;
    
    let mut tetrahedrons = Vec::new();
    
    for i in start_i..end_i {
        for j in start_j..end_j {
            let square = [
                (i as f64, j as f64),
                (i as f64 + 1.0, j as f64),
                (i as f64 + 1.0, j as f64 + 1.0),
                (i as f64, j as f64 + 1.0),
            ];
            if polygons_intersect(&polygon, &square) {
                let px = i as f64 + 0.5;
                let py = j as f64 + 0.5;
                let pz = 0.0;
                let qw = 1.0;
                let qx = 0.0;
                let qy = 0.0;
                let qz = 0.0;
                let scale = 1.0;
                tetrahedrons.push((px, py, pz, qw, qx, qy, qz, scale));
            }
        }
    }
    
    println!("{}", tetrahedrons.len());
    for t in tetrahedrons {
        println!(
            "{:.6} {:.6} {:.6} {:.6} {:.6} {:.6} {:.6} {:.6}",
            t.0, t.1, t.2, t.3, t.4, t.5, t.6, t.7
        );
    }
}

fn point_in_polygon(pt: (f64, f64), poly: &[(f64, f64)]) -> bool {
    let (x, y) = pt;
    let mut inside = false;
    let n = poly.len();
    if n == 0 {
        return false;
    }
    let mut j = n - 1;
    for i in 0..n {
        let (xi, yi) = poly[i];
        let (xj, yj) = poly[j];
        if ((yi > y) != (yj > y)) && (x < (xj - xi) * (y - yi) / (yj - yi) + xi) {
            inside = !inside;
        }
        j = i;
    }
    inside
}

fn segments_intersect(a1: (f64, f64), a2: (f64, f64), b1: (f64, f64), b2: (f64, f64)) -> bool {
    let dx1 = a2.0 - a1.0;
    let dy1 = a2.1 - a1.1;
    let dx2 = b2.0 - b1.0;
    let dy2 = b2.1 - b1.1;
    let denom = dx1 * dy2 - dy1 * dx2;
    
    if denom.abs() < 1e-9 {
        return false;
    }
    
    let dx3 = b1.0 - a1.0;
    let dy3 = b1.1 - a1.1;
    let t = (dx3 * dy2 - dy3 * dx2) / denom;
    let u = (dx3 * dy1 - dy3 * dx1) / denom;
    
    t >= 0.0 && t <= 1.0 && u >= 0.0 && u <= 1.0
}

fn polygons_intersect(poly1: &[(f64, f64)], poly2: &[(f64, f64)]) -> bool {
    for pt in poly1 {
        if point_in_polygon(*pt, poly2) {
            return true;
        }
    }
    for pt in poly2 {
        if point_in_polygon(*pt, poly1) {
            return true;
        }
    }
    
    let n1 = poly1.len();
    let n2 = poly2.len();
    if n1 < 2 || n2 < 2 {
        return false;
    }
    
    for i in 0..n1 {
        let a1 = poly1[i];
        let a2 = poly1[(i + 1) % n1];
        for j in 0..n2 {
            let b1 = poly2[j];
            let b2 = poly2[(j + 1) % n2];
            if segments_intersect(a1, a2, b1, b2) {
                return true;
            }
        }
    }
    false
}
```

### Explanation
1. **Input Parsing**: The input is read and parsed into the number of vertices (NV), the polygon vertices, and the sun direction vector.
2. **Bounding Box Calculation**: The axis-aligned bounding box (AABB) of the polygon is computed to determine the grid range for processing.
3. **Grid Processing**: For each unit square in the grid that overlaps the AABB:
   - The square's vertices are checked for intersection with the polygon using the ray casting algorithm (for point-in-polygon tests) and segment intersection checks.
   - If the square intersects the polygon, a tetrahedron is generated with:
     - Center at the square's center (i + 0.5, j + 0.5, 0.0).
     - Identity quaternion (no rotation).
     - Scale factor 1.0 (ensuring the shadow is a 2x2 square, non-overlapping with adjacent squares).
4. **Output**: The number of tetrahedrons is printed, followed by each tetrahedron's parameters (position, quaternion, scale).

This approach efficiently covers the polygon with non-overlapping tetrahedrons by leveraging a grid-based strategy, ensuring correctness and simplicity while adhering to the problem constraints.
