To solve this problem, we need to identify outliers in drillhole assay data that likely contain typos or measurement errors. These outliers do not correlate well with spatially neighboring data points. The solution must efficiently handle datasets ranging from small exploration projects (10 holes) to massive mining surveys (200,000 holes) within a 5-minute time limit.

### Approach
1. **Data Parsing and 3D Position Calculation**:
   - Read the number of holes and properties from stdin.
   - For each hole, parse its start coordinates, direction vector, length, and number of samples.
   - Normalize the direction vector to ensure consistent sampling intervals.
   - Calculate the 3D position (x, y, z) for each sample along the hole using linear interpolation.

2. **Spatial Indexing with KD-Tree**:
   - Construct a KD-Tree to efficiently query the k-nearest neighbors (k-NN) for each sample point.
   - The KD-Tree allows logarithmic time complexity for nearest neighbor searches, which is crucial for handling large datasets.

3. **Outlier Detection**:
   - For each sample, compute the median and Median Absolute Deviation (MAD) of each property among its k-nearest neighbors (excluding the sample itself).
   - Calculate a confidence score based on how many MAD units the sample's value deviates from the median. A higher score indicates a higher likelihood of being an outlier.
   - Use MAD instead of standard deviation for robustness against outliers in the neighborhood.

4. **Adaptive Strategy Based on Dataset Size**:
   - For small datasets (≤1000 samples), use a brute-force approach to find k-NN (O(n²) but feasible for small n).
   - For larger datasets, use the KD-Tree for efficient k-NN queries (O(n log n)).

5. **Output**:
   - Sort suspect entries by confidence score in descending order.
   - Output the number of suspects followed by each suspect's details (hole ID, sample index, property name, confidence score).

#[derive(Debug, Clone)]
struct Point {
    x: f64,
    y: f64,
    z: f64,

#[derive(Debug)]
struct Node {
    point: Point,
    index: usize,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

struct KDTree {
    root: Option<Box<Node>>,
    k: usize,
}

impl KDTree {
    fn new(points: &[Point]) -> Self {
        if points.is_empty() {
            KDTree {
                root: None,
                k: 0,
            }
        } else {
            KDTree {
                root: Some(Self::build_tree(points, 0)),
                k: 3,
            }
        }
    }

    fn build_tree(points: &[Point], depth: usize) -> Box<Node> {
        let axis = depth % 3;
        let mut points_vec = points.to_vec();
        points_vec.sort_by(|a, b| match axis {
            0 => a.x.partial_cmp(&b.x).unwrap(),
            1 => a.y.partial_cmp(&b.y).unwrap(),
            2 => a.z.partial_cmp(&b.z).unwrap(),
            _ => unreachable!(),
        });
        let mid = points_vec.len() / 2;
        let node = Node {
            point: points_vec[mid].clone(),
            index: mid,
            left: if mid > 0 {
                Some(Box::new(Self::build_tree(&points_vec[..mid], depth + 1)))
            } else {
                None
            },
            right: if mid + 1 < points_vec.len() {
                Some(Box::new(Self::build_tree(&points_vec[mid + 1..], depth + 1)))
            } else {
                None
            },
        };
        Box::new(node)
    }

    fn query_knn(&self, target: &Point, k: usize) -> Vec<(f64, usize)> {
        let mut heap = BinaryHeap::with_capacity(k + 1);
        self.knn_search(self.root.as_ref(), target, 0, k, &mut heap);
        let mut res: Vec<(f64, usize)> = heap.into_sorted_vec();
        res.reverse();
        res
    }

    fn knn_search(
        &self,
        node: Option<&Node>,
        target: &Point,
        depth: usize,
        k: usize,
        heap: &mut BinaryHeap<(f64, usize)>,
    ) {
        if let Some(n) = node {
            let dist = self.squared_distance(&n.point, target);
            heap.push((dist, n.index));
            if heap.len() > k {
                heap.pop();
            }

            let axis = depth % 3;
            let (first, second) = match axis {
                0 => (
                    (target.x < n.point.x, n.left.as_ref(), n.right.as_ref()),
                    (target.x >= n.point.x, n.right.as_ref(), n.left.as_ref()),
                ),
                1 => (
                    (target.y < n.point.y, n.left.as_ref(), n.right.as_ref()),
                    (target.y >= n.point.y, n.right.as_ref(), n.left.as_ref()),
                ),
                2 => (
                    (target.z < n.point.z, n.left.as_ref(), n.right.as_ref()),
                    (target.z >= n.point.z, n.right.as_ref(), n.left.as_ref()),
                ),
                _ => unreachable!(),
            };

            let (go_first_first, go_first_node, go_first_other) = first;
            let (go_second_first, go_second_node, go_second_other) = second;

            if go_first_first {
                self.knn_search(go_first_node, target, depth + 1, k, heap);
                let diff = match axis {
                    0 => target.x - n.point.x,
                    1 => target.y - n.point.y,
                    2 => target.z - n.point.z,
                    _ => 0.0,
                };
                if heap.len() < k || diff * diff < *heap.peek().unwrap().0 {
                    self.knn_search(go_first_other, target, depth + 1, k, heap);
                }
            } else {
                self.knn_search(go_second_node, target, depth + 1, k, heap);
                let diff = match axis {
                    0 => target.x - n.point.x,
                    1 => target.y - n.point.y,
                    2 => target.z - n.point.z,
                    _ => 0.0,
                };
                if heap.len() < k || diff * diff < *heap.peek().unwrap().0 {
                    self.knn_search(go_second_other, target, depth + 1, k, heap);
                }
            }
        }
    }

    fn squared_distance(&self, p1: &Point, p2: &Point) -> f64 {
        let dx = p1.x - p2.x;
        let dy = p1.y - p2.y;
        let dz = p1.z - p2.z;
        dx * dx + dy * dy + dz * dz
    }
}

### Explanation
1. **Data Parsing**: The program reads the number of holes and properties, followed by hole specifications (start coordinates, direction vector, length, and number of samples). For each sample along a hole, it calculates the 3D position.
2. **Spatial Indexing**: A KD-Tree is built to enable efficient k-nearest neighbor (k-NN) queries. For small datasets (≤1000 samples), a brute-force approach is used due to its simplicity.
3. **Outlier Detection**: For each sample, the program computes the median and MAD of each property among its k-nearest neighbors. The confidence score is derived from how many MAD units the sample's value deviates from the median. Samples with a confidence score > 3.0 are flagged as suspects.
4. **Output**: Suspects are sorted by confidence in descending order and printed with their hole ID, sample index, property name, and confidence score.

This approach efficiently handles varying dataset sizes by adapting the k-NN search strategy, ensuring optimal performance from small to large-scale data while robustly identifying potential outliers in drillhole assay data.
