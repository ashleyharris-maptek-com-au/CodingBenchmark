We need a snake game solver that works for any dimension, from 2D to 20D or more.  
The main challenge is that the search space grows exponentially with dimension, so we cannot use a full grid representation for high dimensions.  

We’ll need to:  

1. **Represent positions** as tuples of integers (`std::vector<int>` or `std::array` for small fixed D, but here D can vary at runtime, so `std::vector<int>` is natural).  
2. **Store obstacles and snake body** in a hash set for O(1) lookups.  
3. **Pathfinding** must work in N-D space, likely using BFS on the implicit graph of positions.  
4. **Memory efficiency** — we cannot store all grid points in high dimensions.  

---

## Strategy Outline

- **State representation**:  
  - Snake: `std::deque<std::vector<int>>` for the body (head at front).  
  - Obstacles: `std::unordered_set` hashed positions.  
  - Food: `std::unordered_set` hashed positions.  

- **Movement**:  
  In N-D, from a position `p`, neighbors are `p[i] += 1` or `p[i] -= 1` for each dimension `i`, staying within bounds.

- **Pathfinding to food**:  
  Use BFS from head to nearest food, avoiding obstacles and snake body (except tail if moving).  
  If no path to food, move to maximize space (Hamiltonian / survival mode).

- **High-dimension adaptation**:  
  BFS will still work because we only explore reachable states, not the whole grid.  
  But in huge dimensions, branching factor is `2*D`, which can be large (e.g., 40 neighbors for 20D).  
  We’ll need to limit search depth.

- **Fallback**:  
  If BFS to food fails, use a safe move that doesn’t kill immediately, using BFS to find a move that keeps us alive.

---

## Implementation Plan

1. **Parse input** into D, bounds, snake, food, obstacles.
2. **Game loop** until win, lose, or max_turns.
3. **Each turn**:  
   - If food at head: eat it (increase length, remove food).  
   - Compute BFS path to nearest food.  
   - If path exists, follow first step.  
   - Else, find a safe move (BFS to any far target, or just avoid death).  
   - If no safe move, move randomly (maybe lose).  
4. **Output** axis and direction.

## Code

```cpp
#include <iostream>
#include <vector>
#include <deque>
#include <unordered_set>
#include <queue>
#include <algorithm>
#include <tuple>
#include <cstdint>
#include <string>
#include <random>

// Hash for vector<int> to use in unordered_set
struct VectorHash {
    std::size_t operator()(const std::vector<int>& v) const {
        std::size_t seed = v.size();
        for (const auto& i : v) {
            seed ^= std::hash<int>{}(i) + 0x9e3779b9 + (seed << 6) + (seed >> 2);
        }
        return seed;
    }
};

using PosSet = std::unordered_set<std::vector<int>, VectorHash>;

class NDimensionalSnake {
private:
    int D;
    int max_turns;
    std::vector<int> bounds;
    std::deque<std::vector<int>> snake;
    PosSet food_set;
    PosSet obstacle_set;
    int turns = 0;
    std::mt19937 rng;

    // For BFS
    struct BFSNode {
        std::vector<int> pos;
        int axis;
        int dir;
        BFSNode* prev;
        BFSNode(std::vector<int> p, int a, int d, BFSNode* pr) 
            : pos(std::move(p)), axis(a), dir(d), prev(pr) {}
    };

public:
    NDimensionalSnake() : rng(std::random_device{}()) {}

    void read_input() {
        std::cin >> D >> max_turns;
        bounds.resize(D);
        for (int i = 0; i < D; ++i) {
            std::cin >> bounds[i];
        }

        int snake_length;
        std::cin >> snake_length;
        snake.resize(snake_length);
        for (int i = 0; i < snake_length; ++i) {
            snake[i].resize(D);
            for (int j = 0; j < D; ++j) {
                std::cin >> snake[i][j];
            }
        }

        int F;
        std::cin >> F;
        for (int i = 0; i < F; ++i) {
            std::vector<int> pos(D);
            for (int j = 0; j < D; ++j) {
                std::cin >> pos[j];
            }
            food_set.insert(pos);
        }

        int O;
        std::cin >> O;
        for (int i = 0; i < O; ++i) {
            std::vector<int> pos(D);
            for (int j = 0; j < D; ++j) {
                std::cin >> pos[j];
            }
            obstacle_set.insert(pos);
        }
    }

    bool in_bounds(const std::vector<int>& pos) const {
        for (int i = 0; i < D; ++i) {
            if (pos[i] < 1 || pos[i] > bounds[i]) return false;
        }
        return true;
    }

    bool is_free(const std::vector<int>& pos, const std::vector<int>& ignore_tail) const {
        if (!in_bounds(pos)) return false;
        if (obstacle_set.count(pos)) return false;
        // Check snake body except tail (if moving, tail will move forward)
        // We'll check all except tail if we're not eating
        // Simpler: check all body except head (since head is current)
        // But here pos is future head, so compare with all current body except tail if move
        // We'll handle in BFS by passing tail pos to ignore.
        for (size_t i = 0; i < snake.size(); ++i) {
            if (snake[i] == pos) {
                // If pos == tail and tail will move, it's free
                if (pos == ignore_tail) continue;
                return false;
            }
        }
        return true;
    }

    // BFS to nearest food, returns (axis, dir) of first step or (-1,0) if none
    std::pair<int, int> bfs_to_food(const std::vector<int>& start, const std::vector<int>& tail) {
        PosSet visited;
        std::queue<BFSNode*> q;
        visited.insert(start);
        q.push(new BFSNode(start, -1, 0, nullptr));

        while (!q.empty()) {
            BFSNode* cur = q.front(); q.pop();

            // If this is food (and not start), reconstruct first move
            if (food_set.count(cur->pos) && cur->pos != start) {
                BFSNode* node = cur;
                while (node->prev != nullptr && node->prev->prev != nullptr) {
                    node = node->prev;
                }
                int ax = node->axis;
                int dir = node->dir;
                // Clean up memory
                // (We should clean all nodes, but for simplicity, we skip here)
                // In production, use unique_ptr or vector storage.
                return {ax, dir};
            }

            // Generate neighbors
            for (int dim = 0; dim < D; ++dim) {
                for (int delta = -1; delta <= 1; delta += 2) {
                    std::vector<int> nxt = cur->pos;
                    nxt[dim] += delta;
                    if (!in_bounds(nxt)) continue;
                    if (visited.count(nxt)) continue;
                    if (!is_free(nxt, tail)) continue;
                    visited.insert(nxt);
                    int first_axis = (cur->axis == -1) ? dim : cur->axis;
                    int first_dir = (cur->axis == -1) ? delta : cur->dir;
                    q.push(new BFSNode(nxt, first_axis, first_dir, cur));
                }
            }
        }
        return {-1, 0}; // no path
    }

    // BFS to any farthest point for survival, returns first move
    std::pair<int, int> bfs_safe_move(const std::vector<int>& start, const std::vector<int>& tail) {
        PosSet visited;
        std::queue<BFSNode*> q;
        visited.insert(start);
        q.push(new BFSNode(start, -1, 0, nullptr));

        BFSNode* farthest = nullptr;
        int max_dist = 0;

        while (!q.empty()) {
            BFSNode* cur = q.front(); q.pop();

            // Record farthest node from start
            int dist = 0;
            if (cur->axis != -1) {
                dist = 1; // simple
                // We'll just track last visited
                farthest = cur;
            }

            for (int dim = 0; dim < D; ++dim) {
                for (int delta = -1; delta <= 1; delta += 2) {
                    std::vector<int> nxt = cur->pos;
                    nxt[dim] += delta;
                    if (!in_bounds(nxt)) continue;
                    if (visited.count(nxt)) continue;
                    if (!is_free(nxt, tail)) continue;
                    visited.insert(nxt);
                    int first_axis = (cur->axis == -1) ? dim : cur->axis;
                    int first_dir = (cur->axis == -1) ? delta : cur->dir;
                    q.push(new BFSNode(nxt, first_axis, first_dir, cur));
                }
            }
        }

        if (farthest != nullptr) {
            // Reconstruct first move
            BFSNode* node = farthest;
            while (node->prev != nullptr && node->prev->prev != nullptr) {
                node = node->prev;
            }
            return {node->axis, node->dir};
        }
        return {-1, 0};
    }

    void play() {
        while (turns < max_turns && !food_set.empty()) {
            // Check if head is on food
            bool eat = false;
            if (food_set.count(snake.front())) {
                eat = true;
                food_set.erase(snake.front());
            }

            // Find tail (will move forward unless we eat)
            std::vector<int> tail = snake.back();
            if (!eat) {
                snake.pop_back(); // tail moves
            }

            // Decide move
            std::pair<int, int> move = bfs_to_food(snake.front(), tail);
            if (move.first == -1) {
                // No path to food, try safe move
                move = bfs_safe_move(snake.front(), tail);
                if (move.first == -1) {
                    // No safe move, random move
                    std::vector<int> dirs;
                    for (int dim = 0; dim < D; ++dim) {
                        for (int d = -1; d <= 1; d += 2) {
                            std::vector<int> nxt = snake.front();
                            nxt[dim] += d;
                            if (is_free(nxt, tail)) {
                                dirs.push_back(dim * 2 + (d > 0 ? 1 : 0));
                            }
                        }
                    }
                    if (dirs.empty()) {
                        // Lose
                        std::cout << "0 -1\n"; // arbitrary, will die
                        std::exit(0);
                    }
                    std::uniform_int_distribution<> dis(0, dirs.size() - 1);
                    int choice = dirs[dis(rng)];
                    move.first = choice / 2;
                    move.second = (choice % 2 == 1) ? 1 : -1;
                }
            }

            // Apply move
            std::vector<int> new_head = snake.front();
            new_head[move.first] += move.second;
            snake.push_front(new_head);

            // Output
            std::cout << move.first << " " << move.second << "\n";
            std::flush(std::cout);

            turns++;
        }
    }
};

int main() {
    NDimensionalSnake game;
    game.read_input();
    game.play();
    return 0;
}
```

---

## Key Points

1. **Hash-based storage** for obstacles and food — O(1) lookups, memory proportional to number of obstacles/food, not grid size.
2. **BFS for pathfinding** explores only reachable states, so it works even in high dimensions if the board isn’t packed.
3. **Tail handling** — when not eating, tail moves, so it’s not an obstacle for the next move.
4. **Fallback strategies** to avoid dying immediately if no path to food exists.
5. **Random move** as last resort if completely trapped.

This should work from 2D to 20D, given the constraints that obstacles and food are sparse (otherwise BFS might be slow).  
For extreme dimensions with many obstacles, you might need heuristic search (A*) with a good distance metric, but BFS is a safe start.
